## 表概述

【是什么】预算资产负债表，反映本公司期末财务状况与资产负债结构。
【谁填】系统汇总生成，由各项资产、负债和权益预算表自动驱动，财务人员审核平衡。
【怎么填】按“年初余额、本年发生额、调整额、期末余额”年度四列展开；期末余额=年初余额+本年发生额+调整额，往来款按权责发生制滚动。
【系统怎么处理】单体出具各子公司资产负债表，净利润滚入未分配利润。

## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 项目名称 | 本表 | 资产负债表项目名称 |
| 年初余额 | 本表录入 | 预算年度年初余额，即上年末资产负债表期末余额；位于项目名称之后 |
| 本年发生额 | 各业务与财务编制表 | 本年影响资产、负债、权益余额的发生净额，来自 BA、BB、BF 等预算编制表按报表项目年度归集；不展开到月 |
| 调整额 | 本表录入 | 预算编制阶段年度调整额，财务人员按报表项目手工录入；不展开到月 |
| 期末余额 | 本表公式 | =年初余额+本年发生额+调整额；用于资产=负债+所有者权益勾稽 |

## ③ 关键规则要点

**BO.BS 资产负债表**

- BO.BS 资产负债表按年处理，不展开到月：列结构为「年初余额 → 本年发生额 → 调整额 → 期末余额」，期末余额 = 年初余额 + 本年发生额 + 调整额，需做勾稽校验。
- 往来科目（应收账款 1122、预付账款 1123、应付账款 2202、合同负债 2204）按权责发生制滚动（年初余额 + 本年发生额 + 调整额 = 期末余额），在 BO.BS 中正常列报余额并做期末余额勾稽；资产、存货仍按到货额/验收额（权责发生制）确认，预付款与验收付款是独立付款度量，仅驱动 CF-05/CF-14 现金流。

**BO.B 业务预算汇总表**

- 销售多维汇总、存货进销存汇总、资本化支出汇总、费用汇总。

## ④ 适用业务情形

**适用于**

- 汇总各科目余额形成预算资产负债表并校验勾稽

**不适用于**

- 损益（属 BO.PL）、现金流（属 BO.CF）

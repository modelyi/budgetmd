## ② 字段与值说明

| 字段 | 来源 | 说明 | 填报要求 |
| :--- | :--- | :--- | :--- |
| 法人公司 | AA.2 法人组织架构 | 处置主体（资产卡片所在法人公司）；各法人单体分别入账 | 必输；下拉选择 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 资产原领用部门（默认明细到二级部门），仅作费用/资产归属识别 | 必输；下拉选择 |
| 资产类别 | AA.9 资产类别与折旧 | 资产类别（代表大类-小类层级）；与 BB.4.4 / BB.4.5 同口径，便于按资产勾稽 | 必输；下拉选择 |
| 资产描述 | 本表录入 | 文本字段，仅用于人眼识别资产（设备名称/规格/编号），不参与任何测算与分录 | 选填；手工填报 |
| 处置方式 | 本表枚举：对外出售 / 报废变卖 | 处置方式两类（枚举）：对外出售、报废变卖 | 必输；下拉选择；枚举（两类）：对外出售、报废变卖 |
| 资产原值 | 本表录入或按资产卡片带出 | 全年合计+1~12月；金额填在处置月份列；对应 BO.BS 固定资产原值减少 | 必输；手工填报；金额一律填在处置月份列，全年合计自动求和 |
| 累计折旧 | 本表录入或按资产卡片带出 | 全年合计+1~12月；填在处置月份列；对应 BO.BS 累计折旧减少（与 BB.4.4/BB.4.5 计提口径分开列示） | 必输；手工填报；金额一律填在处置月份列，全年合计自动求和 |
| 资产净值 | 本表公式 | = 资产原值 − 累计折旧；对应 BO.BS 固定资产净值减少 | 公式自动计算；行内公式 = 资产原值 − 累计折旧，不允许手工改数 |
| 处置收款(不含税) | 本表录入 | 全年合计+1~12月；处置损益测算基数 | 必输；手工填报；金额一律填在处置月份列，全年合计自动求和 |
| 处置收款(含税) | 本表录入 | 全年合计+1~12月；含税与不含税差额即增值税；含税列驱动 BO.CF CF-13.1 处置长期资产收回的现金净额 | 必输；手工填报；金额一律填在处置月份列，全年合计自动求和 |
| 处置损益 | 本表公式 | = 处置收款(不含税) − 资产净值；正数进 6115 资产处置收益，负数（报废净损失）进 6302 营业外支出 | 公式自动计算；行内公式 = 处置收款(不含税) − 资产净值（正数收益、负数损失），不允许手工改数 |

## ④ 适用业务情形

**适用于**

- 本年度固定资产与无形资产的对外出售、报废变卖（含残值变卖）

**不适用于**

- 资产新增（BB.3.1/BB.3.2/BB.4.1/BB.4.3）
- 折旧与摊销计提（BB.4.4/BB.4.5）
- 存货处置与盘亏报废（在 BB.3.X 进销存表直接调整）

## ⑤ 预算编制视角：数据关系总结

资产处置预算表（独立表单，5 维度列 + 6×13=78 度量列，共 83 列）：一行一笔处置，登记处置资产的原值、累计折旧与处置收款（不含税/含税），按行内公式计算资产净值与处置损益；覆盖对外出售、报废变卖两类处置方式，是固定资产/无形资产减少与资产处置现金流入的唯一编制入口。

**数据来源（上游）**

## ⑥ 财务报表项转换规则

本表共用口径：处置分录按法人公司汇总生成，各法人单体报表分别入账；处置收款按含税列进处置固定资产、无形资产和其他长期资产收回的现金净额，增值税内含于含税收款、不在支付的各项税费重复计提；本表不提折旧。固定资产按净值列示（固定资产＝原值−累计折旧），分录统一以「固定资产（净值）」表述，累计折旧/原值仅作括号明细说明。

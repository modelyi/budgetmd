## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 法人公司 | AA.2 法人组织架构 | 处置主体（资产卡片所在法人公司）；各法人单体分别入账 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 资产原领用部门（默认明细到二级部门），仅作费用/资产归属识别 |
| 资产类别 | AA.9 资产类别与折旧 | 资产类别（代表大类-小类层级）；与 BB.4.4 / BB.4.5 同口径，便于按资产勾稽 |
| 资产描述 | 本表录入 | 文本字段，仅用于人眼识别资产（设备名称/规格/编号），不参与任何测算与分录 |
| 处置方式 | 本表枚举：对外出售 / 报废变卖 | 处置方式两类（枚举）：对外出售、报废变卖 |
| 资产原值 | 本表录入或按资产卡片带出 | 全年合计+1~12月；金额填在处置月份列；对应 BO.BS 固定资产原值减少 |
| 累计折旧 | 本表录入或按资产卡片带出 | 全年合计+1~12月；填在处置月份列；对应 BO.BS 累计折旧减少（与 BB.4.4/BB.4.5 计提口径分开列示） |
| 资产净值 | 本表公式 | = 资产原值 − 累计折旧；对应 BO.BS 固定资产净值减少 |
| 处置收款(不含税) | 本表录入 | 全年合计+1~12月；处置损益测算基数 |
| 处置收款(含税) | 本表录入 | 全年合计+1~12月；含税与不含税差额即增值税；含税列驱动 BO.CF CF-13.1 处置长期资产收回的现金净额 |
| 处置损益 | 本表公式 | = 处置收款(不含税) − 资产净值；正数进 6115 资产处置收益，负数（报废净损失）进 6302 营业外支出 |

## ③ 关键规则要点

**BB.4.6 资产处置预算表**

- 定位：固定资产与无形资产处置的编制入口，一行一笔处置。维度=法人公司、预算部门、资产类别、资产描述、处置方式（5 列）；度量=【全年合计】+1~12月，每月 6 个子列：资产原值、累计折旧、资产净值、处置收款-不含税、处置收款-含税、处置损益（两行制表头共 83 列）。
- 处置方式两类（枚举）：对外出售、报废变卖。
- 行内公式：资产净值 = 资产原值 − 累计折旧；处置损益 = 处置收款(不含税) − 资产净值（正数收益、负数损失）。金额一律填在处置月份列，全年合计自动求和；不足一年的资产不另设折旧口径，折旧已在 BB.4.4/BB.4.5 计提，本表不计提折旧。

## ④ 适用业务情形

**适用于**

- 本年度固定资产与无形资产的对外出售、报废变卖（含残值变卖）

**不适用于**

- 资产新增（BB.3.1/BB.3.2/BB.4.1/BB.4.3）
- 折旧与摊销计提（BB.4.4/BB.4.5）
- 存货处置与盘亏报废（在 BB.3.X 进销存表直接调整）

## ⑤ 预算编制视角：数据关系总结

资产处置预算表（独立表单，5 维度列 + 6×13=78 度量列，共 83 列）：一行一笔处置，登记处置资产的原值、累计折旧与处置收款（不含税/含税），按行内公式计算资产净值与处置损益；覆盖对外出售、报废变卖两类处置方式，是固定资产/无形资产减少与资产处置现金流入的唯一编制入口。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 资产类别与折旧 | AA.9 | 资产类别（大类-小类）、折旧参数 | 资产类别取 AA.9，与 BB.4.4/BB.4.5 同口径，便于按资产勾稽 |
| 法人组织架构 | AA.2 | 法人公司、持股比例 | 处置主体（法人公司）来源；各法人单体分别入账 |
| 存量资产折旧计算表 | BB.4.4 | 原值、累计折旧、资产领用部门 | 按资产卡片带出原值与累计折旧（可选：手工填报时可参照存量台账取数） |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.BS 资产负债表—固定资产(净值)1601 | 资产净值减少（= 原值 − 累计折旧），与 BB.4.X.A 折旧合计并列为本期减少项（单体口径） |
| BO.PL 利润表—资产处置收益(6115) / 营业外支出(6302) | 处置损益 = 处置收款(不含税) − 资产净值；正数进 6115，报废净损失进 6302 |
| BO.CF 现金流量表—CF-13.1 处置固定资产、无形资产和其他长期资产收回的现金净额 | 取本表处置收款-含税（含税现金口径），按处置月份列归集 |
| BO.BS 资产负债表—应交税费(2221) | 处置收款含税与不含税的差额即增值税销项税额（在收付时点内含，不在 CF-07 重复计提） |

**关键编制规则**

- 一行一笔处置；金额填在处置月份列，全年合计 = 各月求和；资产净值与处置损益为行内公式，不允许手工改数。
- 本表不计提折旧（属 BB.4.4/BB.4.5）、不单独计提增值税（含税−不含税即增值税）；法人归属按处置主体（资产卡片所在法人）。

## ⑥ 财务报表项转换规则

**对外出售资产（处置收款与处置损益确认）** `处置方式=对外出售：资产原值 / 累计折旧 / 处置收款-不含税 / 处置收款-含税`

- 取数说明：BB.4.6 资产处置预算表·处置方式=对外出售（按法人公司+处置月份取数）
- 损益表 PL：资产处置收益 6115 (+)：处置损益 = 处置收款(不含税) − 资产净值（= 原值 − 累计折旧）
- 资产负债表 BS：固定资产(净值) 1601 (−)；货币资金 1001 (+)；应交税费—应交增值税(销项税额) 2221 (+)
- 现金流量表 CF：CF-13.1 处置固定资产、无形资产和其他长期资产收回的现金净额 (+)（取含税收款，按处置月份）
- 科目影响：借：货币资金(1001)（含税收款）、累计折旧（已提部分）；贷：固定资产—原值(1601)、应交税费—应交增值税(销项税额)；差额借/贷：资产处置收益(6115)
- 其他备注：按法人公司汇总生成分录，各法人单体报表分别入账；处置收款按含税列进 CF-13.1，增值税内含于含税收款、不在 CF-07 重复计提；本表不计提折旧。

**报废变卖清理** `处置方式=报废变卖：资产原值 / 累计折旧 / 残值变卖款-不含税 / 残值变卖款-含税`

- 取数说明：BB.4.6 资产处置预算表·处置方式=报废变卖
- 损益表 PL：报废净损失计入 6302 营业外支出 (−)：= 残值变卖款(不含税) − 资产净值（为负）；如为净收益计入 6115
- 资产负债表 BS：固定资产(净值) 1601 (−)；货币资金 1001 (+)（残值变卖款）
- 现金流量表 CF：CF-13.1 (+)（残值变卖款含税；无变卖款时本行为 0）
- 科目影响：借：货币资金(1001)（残值变卖款含税）、累计折旧、营业外支出(6302)（净损失）；贷：固定资产—原值(1601)、应交税费—应交增值税(销项税额)
- 其他备注：报废无变卖款时处置收款为 0，仅减少固定资产净值并确认损失；不产生额外现金流；残值变卖款仍按含税列进 CF-13.1。

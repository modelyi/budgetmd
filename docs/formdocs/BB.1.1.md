## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 合同编码 | 合同主数据 / 本表录入 | 存量合同从合同主数据选择；新增商业机会可手工录入业务合同编码；不得新增预算虚拟编码列 |
| 合同名称 | 合同主数据 / 本表录入 | 存量合同按合同编码带出；新增商业机会可手工补录合同或商机名称 |
| 合同性质 | AB.5 合同性质字典 | 仅允许存量框架合同、新增商业机会 |
| 客户 | AA.4.a 客户主数据 | 签约客户，从客户主数据选择 |
| 预算项目 | AA.6 预算项目主数据 | 本笔签约对应的预算项目 |
| 预算产品 | AA.7 预算产品主数据 | 签约产品；选择后自动带出产品类别与收入方式，允许按业务需要修改 |
| 机台 | 本表录入 | 机台名称或标识，文本，用户必输 |
| 区域 | 区域主数据 | 合同/项目归属区域；表样第H列=区域 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 签约归属预算部门；表样第I列，默认明细到二级部门 |
| 法人公司 | AA.2 法人组织架构 | 签约归属法人主体 |
| 产品类别 | AB.3 产品类别字典 / AM.1 产品与收入方式映射 | 由预算产品带出，允许修改 |
| 收入方式 | AB.4 收入确认方式字典 / AM.1 产品与收入方式映射 | 由预算产品带出，允许修改 |
| 本年签约额 | 本表公式 | 全年合计=1~12月签约额之和，不可直接编辑；金额不含税，单位万元 |
| 月度签约额 | 本表录入 | 按月填报本年1~12月签约额；金额不含税，单位万元，不允许负数或留空，未发生填0 |
| 下年签约额 | 本表录入 | 按合同填报下年签约额；金额不含税，单位万元 |
| 后年签约额 | 本表录入 | 按合同填报后年签约额；金额不含税，单位万元 |
| 编制说明 | 本表录入 | 补充合同签约预算的业务假设或特殊事项 |

## ③ 关键规则要点

**BB.1.1 合同签约额预算表**

- 字段及表样按列序填写：A列合同编码、B列合同名称、C列合同性质、D列客户、E列预算项目、F列预算产品、G列机台（文本，用户必输）、H列区域、I列预算部门、J列法人公司、K列产品类别、L列收入方式，后接本年签约额（全年合计+1~12月）、下年签约额、后年签约额和编制说明
- 合同编码、合同名称、客户、预算项目、预算产品、机台、区域、预算部门、法人公司等维度按表样列序填写；合同性质仅允许「存量框架合同 / 新增商业机会」两值。
- 预算产品选择后自动带出产品类别与收入方式，允许按业务需要修改；机台字段为文本，由用户输入，说明里强调用户必输；I列为「预算部门」口径，默认明细到二级部门。
- 金额（本年 1~12 月、下年、后年）均不含税，不允许负数或留空，未发生填 0。
- 本年签约额合计由 1~12 月签约额自动汇总，不可直接编辑；三年签约额均为 0 时给出确认提示。

## ④ 适用业务情形

**适用于**

- 本年度新签订、新增的销售合同（含新增商业机会），按合同录入本年1~12月及下年、后年签约额

**不适用于**

- 上年结转的存量在手订单执行跟踪（属 BB.1.2）
- 合同已确认的收入/成本核算（属 BB.1.2/BB.1.3）

## ⑤ 预算编制视角：数据关系总结

合同签约额预算是收入预算的"起点账本"，按合同维度登记全年各月新签合同与存量框架合同的签约额（不含税）。它回答"未来一年签了多少单、盘子有多大"，是销售收入的预测源头；但签约只是签了合同，不等于已经确认收入。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 合同主数据 / 本表录入 | MASTER_CONTRACTS | 合同编码、合同名称 | 存量合同按合同编码选择并带出名称；新增商业机会可手工录入，不设置预算虚拟编码列 |
| 区域主数据 | 区域主数据 | 区域 | 合同/项目归属区域，对应表样H列=区域 |
| 客户主数据 | AA.4.a | 客户 | 签约对象，从客户主数据下拉选择 |
| 预算项目主数据 | AA.6 | 预算项目 | 这笔签约对应的销售项目，从预算项目主数据选择 |
| 预算产品主数据 | AA.7 | 预算产品 | 签约销售的产品，选择后自动带出产品类别与收入方式 |
| 行政部门字典 | AA.5 | 预算部门 | 签约归属预算部门，对应表样I列=预算部门，默认明细到二级部门 |
| 法人组织架构 | AA.2 | 法人公司 | 签约归属的法人公司 |
| 合同性质字典 | AB.5 | 合同性质 | 区分存量框架合同与新增商业机会 |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BB.1.2 软硬件收入与成本预算 | 签约额是收入确认的"合同背景"，真正确认收入在 BB.1.2（销量×单价） |
| BB.1.3 技术服务收入与成本预算 | 服务类签约同样只是背景，服务收入在 BB.1.3 单独确认 |

**关键编制规则**

- 签约额是预测口径、不是收入确认依据，避免与 BB.1.2/BB.1.3 的收入重复计入。
- 全部金额不含税，不处理增值税。
- 同一合同编码允许多行拆分，全年合计须等于 1~12 月签约额之和。

## ⑥ 财务报表项转换规则

**签约额** `1~12月签约额`

- 取数说明：取自本表1~12月签约额填报值，全年合计=SUM(1~12月)
- 损益表 PL：—（签约≠收入确认，不影响损益表）
- 资产负债表 BS：—
- 现金流量表 CF：—（签约属合同签约口径，不生成预算凭证，不进入三大报表）
- 科目影响：本表不生成会计分录；签约额仅作为收入预算预测指标与合同备查（备查账由系统台账承载，不生成预算凭证），凭证与三表影响由下游收入确认表（BB.1.2/BB.1.3）生成
- 其他备注：同一合同编码（BB.1.1 实际字段为 A列=合同编码、B列=合同名称、G列=机台、H列=区域、I列=预算部门，不存在“预算虚拟编码”字段）允许多行拆分，但全年合计须等于 SUM(m1~m12)；签约额为预测口径，不作为收入确认依据，避免与 BB.1.2 收入确认重复计入。本表不处理增值税、不考虑印花税，签约额均为不含税口径。

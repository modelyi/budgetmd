## ④ 适用业务情形

**适用于**

- 按产品/客户/区域/项目/预算部门（默认明细到二级部门）/费用科目填报销售费用，供销售预算多维汇总分析（BB.1.X）引用

**不适用于**

- 管理/研发/制造费用（属 BB.5.1/BB.5.2）

## ⑤ 预算编制视角：数据关系总结

销售费用明细是"卖东西要花多少钱"的账，登记差旅、招待、广告、佣金等销售费用，按月填报，全年合计自动汇总；独立于预算三表体系，不参与财务结果生成，仅供销售预算多维汇总分析（BB.1.X）的"销售直接费用"列取数。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 预算产品主数据 | AA.7 | 产品 | 费用归属的产品 |
| 客户主数据 | AA.4.a | 客户 | 费用归属的客户 |
| 区域主数据 | 区域 | 区域 | 费用发生的区域 |
| 预算项目主数据 | AA.6 | 项目 | 费用归属的项目 |
| 行政部门字典 | AA.5 | 预算部门 | 费用归属的预算部门，默认明细到二级部门（如"生产一部"而非仅"制造工程部"） |
| 费用科目字典 | 费用科目 | 费用科目 | 差旅/招待/广告/佣金等费用科目 |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BB.1.X 销售预算多维汇总分析—销售直接费用 | 按产品/客户/区域/项目/预算部门/费用科目汇总 → 销售直接费用列 |

**关键编制规则**

- 按月手工填报，全年合计 = SUM(1~12月)。
- 费用科目覆盖差旅/招待/广告/佣金等销售费用类别。

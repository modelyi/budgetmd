## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 预算项目 | AA.6 预算项目主数据 | 预算项目主数据选择 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 预算部门原则上明细到二级部门 |
| 预付款首月(0月)比例 | 本表录入 | 百分比 |
| 预付款次月(1月)比例 | 本表录入 | 百分比 |
| 验收付款首月(0月)比例 | 本表录入 | 百分比 |
| 验收付款第1月比例 | 本表录入 | 百分比 |
| 验收付款第2月比例 | 本表录入 | 百分比 |

## ④ 适用业务情形

**适用于**

- 设备/物料采购预付款、验收付款各月比例的长期规划登记（维度=预算项目×预算部门，后续年度启用）

**不适用于**

- 本年度 BB.3.1/BB.3.3 付款节奏测算取数（本年度不启用本表，付款由各表按月填报）
- 采购金额填报（属 BB.3.1/BB.3.3）

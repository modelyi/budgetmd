## ④ 适用业务情形

**适用于**

- 技术服务类收入与成本预算，含服务人工、服务物料明细的销售填报与财务视角查询

**不适用于**

- 软硬件产品销售收入与成本（属 BB.1.2）
- 服务物料/人工的标准成本设置（属 BAA.3/BAA.4，本表仅引用）

## ⑤ 预算编制视角：数据关系总结

技术服务收入与成本预算是"卖服务"的收入成本账，覆盖维保、软件授权升级等。服务收入单独确认；服务成本由两块构成——服务物料成本（换配件的成本，分好件/坏件）和服务人工成本（交付人员的工时×费率）。收入与收款一律按「签约主体（法人公司）」确认

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 合同主数据 | MASTER_CONTRACTS | 订单编号 | 仅存量订单有要求，新订单可用虚拟订单号或可不填 |
| 行政部门字典 | AA.5 | 预算部门 | 服务项目/订单归属的预算部门，默认明细到二级部门（如"生产一部"而非仅"制造工程部"） |
| 物料主数据 | AA.11 | 服务物料 | 技术服务交付消耗的配件物料 |
| 服务物料定额标准 | BAA.4 | 好件/坏件成本 | 物料成本 = Σ(好件数量×好件成本) − Σ(坏件数量×坏件成本) |
| 岗位工时费率设置 | BAA.3 | 工时标准成本 | 服务人工成本 = 工时数量 × 工时费率 |
| 雇员费用编制 | BB.5.1 | 服务人工冲减 | 技术服务人工不从 BB.5.1 单独计提，而是从雇员费用冲减并单列"服务人工成本" |

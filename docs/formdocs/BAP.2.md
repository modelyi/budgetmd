## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 预算项目 | AA.6 预算项目主数据 | 物料消耗归属的预算项目；领料用途可由预算项目属性自动映射带出（产品化项目→生产类、研发项目→研发类、销售项目→销售类、职能/公共平台项目→管理类及其他） |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 预算部门原则上明细到二级部门 |
| 物料名称 | AA.11 物料主数据 | 消耗物料名称，从物料主数据选择 |
| 物料类别 | AB.9 存货物料类别字典 | 可选值：生产物料/研发物料/服务物料/专项储备/其他物料；与 BB.3.3 物料采购、BB.3.X 进销存品类同一口径，按物料类别归集消耗去向 |
| 领料用途 | 本表录入 | 可选值：研发类/销售类/管理类及其他（生产物料消耗无前置收集表，在 BB.3.X 在制品料行直接手工填报）；决定物料消耗去向（研发类→研发费用、销售类→销售费用、管理类及其他→管理费用），可由预算项目属性自动映射带出 |
| 月度消耗金额 | 本表录入 | 按月手工填报；全年合计=SUM(1~12月)；金额不含税、单位万元、精度 0.1 |
| 全年合计 | 本表公式 | =SUM(1~12月消耗金额) |
| 备注说明 | 本表录入 | 补充物料消耗的业务假设或特殊事项 |

## ④ 适用业务情形

**适用于**

- 各部门月度物料消耗金额汇总（领料用途：生产/研发/销售/管理及其他），是 BB.3.X 进销存出库与在制品领料的唯一取数来源（领料结转分录由 BB.3.X.b 领料与结转视图生成）

**不适用于**

- 研发长期物料消耗（属 BAP.3）

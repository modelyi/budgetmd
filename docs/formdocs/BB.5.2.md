## ④ 适用业务情形

**适用于**

- 由 BAP.1(BA.5)×BAA.8 计算的各法人经营费用转换结果展示（销售/管理/研发/制造四项）

**不适用于**

- 费用明细填报（属 BA.5/外部系统）
- 外部职场租赁租金/物业（由 BB.4.2.a/BB.4.2.a.1 带出）——租赁类费用不在本表按面积公摊

## ⑤ 预算编制视角：数据关系总结

经营费用转换结果表是把外部费用预算模块（BAP.1/BA.5）的费用按法人拆分比例转换得到的各法人经营费用结果表，纯计算展示、不可编辑；研发/管理/销售三项费用直接进损益，制造费用结转进在制品（存货）不进损益，并按月全额驱动经营现金流出。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 费用预算汇总表 | BA.5 | 月度费用金额 | 源头费用数据；按「月度金额 × BAA.8 法人占比」自动计算各法人×项目×部门月度费用 |
| 经营费用转换比例表 | BAA.8 | 法人公司占比 | 按法人公司拆分比例拆分到各法人 |
| 部门属性映射表 | AM.2 | 部门费用性质 | 按部门自动带出费用性质，决定预算科目映射（6601/6602/6603/1405） |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.PL 利润表—销售/管理/研发费用 | 销售→销售费用、管理→管理费用、研发→研发费用 (+)；制造费用不进损益，结转存货 |
| BB.3.X 进销存预算—在制品「费」腿 | 制造费用项金额作为在制品-费转入数（与 BB.4.X.A 并列，两处不得重叠取数） |
| BO.CF 现金流量表—支付的各项税费 | 支付其他与经营活动有关的现金 (+)；现金流支出等于计提数 |
| BO.BS 资产负债表—其他应付款 | 费用计提→应付账款 (+)；付现→货币资金 (−) |

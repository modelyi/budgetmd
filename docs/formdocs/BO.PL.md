## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 序号 | 本表 | 利润表行次序号（一/二/三…为小计行） |
| 项目名称 | 本表 | 利润表项目名称 |
| 上游自动取数 | 各业务与财务编制表 | 1~12月各月上游自动取数，来自 BA（编制前提与假设，含 BB 业务预算编制）、BF（资金与财务预算）所有影响会计报表结果的数据，按科目映射自动归集，只读不可编辑 |
| 编制手工调整 | 本表录入 | 1~12月各月编制手工调整，财务人员在本表手工录入；若有调整需求，直接在本列手工录入 |
| 编制小计 | 本表公式 | 1~12月各月编制小计=上游自动取数+编制手工调整 |
| 全年编制合计 | 本表公式 | =SUM(1~12月编制小计) |
| 年中调整 | 本表录入 | 年中调整数 |
| 执行数 | 本表导入 | 2027年手工导入实际执行数，后续年度再考虑相关接口 |
| 预算实际差异 | 本表公式 | =年度编制合计+年中调整-执行数 |
| 差异说明 | 本表录入 | 差异原因说明 |

## ③ 关键规则要点

**BO.PL 利润表**

- 1~12月预算数：由底层编制表按科目映射自动归集，只读不可编辑。
- 调整项：供财务人员直接手工调节报表结果，允许编辑。
- 全年合计 = SUM(1~12月预算数) + 调整项，公式自动计算（此为 BO.PL 损益表口径）。

## ④ 适用业务情形

**适用于**

- 按会计规则汇总收入/成本/费用形成预算损益表

**不适用于**

- 资产负债（属 BO.BS）、现金流（属 BO.CF）

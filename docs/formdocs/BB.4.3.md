## ④ 适用业务情形

**适用于**

- 非设备及无形资产采购类的其他固定资产、无形资产新增（由企业自主判断后填报），原值按法人公司、资产类别归集后汇入 BB.4.5 增量资产折旧计算表（来源=手工新增）计提折旧（剩余年限(月数)、下月折），本表不计提折旧、不产生折旧分录；资产类别=使用权资产的行（外部 BB.4.2.a 资本化租赁自动生成，原值=租赁负债初始）同样进入 BB.4.5 计提折旧

**不适用于**

- 走标准采购流程的设备及无形资产（属于 BB.3.1）、自制设备工程（属于 BB.4.1）、基建工程（属于 BB.3.2）、存量老资产（属于 BB.4.4）

## ⑤ 预算编制视角：数据关系总结

非设备及无形资产采购类的其他固定资产、无形资产新增（由企业自主判断后填报），手工填报月度资产原值与月度预付款额、月度付款额三个独立度量（6维度列+3×13=45列）；原值按取得时点确认，预付款与付款是两个独立的付款度量、只驱动现金流，二者合计构成 CF-14 基数；原值按法人公司、资产类别归集后汇入 BB.4.5（来源=手工新增）计提折旧（下月折）→ BB.4.X.A；本表不计提折旧、不产生折旧分录。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 预算项目主数据 / 法人组织架构 / 行政部门主数据 | AA.6 / AA.2 / AA.5 | 预算项目、法人公司、预算部门（默认二级部门） | 维度列值域引用；本表为手工填报表，金额无上游业务表取数 |
| 资产类别与折旧 | AA.9 | 资产类别、折旧参数（方法/年限/净残值率） | 资产类别值域对齐 AA.9；原值汇入 BB.4.5 后按 AA.9 参数（下月折）计提折旧 |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BB.4.5 增量资产折旧计算表（来源=手工新增） | 月度资产原值按资产类别、法人公司归集后汇入 BB.4.5（手工新增是增量资产五类来源之一），由 BB.4.5 按 AA.9 折旧参数（下月折）逐卡计提后汇入 BB.4.X.A 折旧费用汇总表；本表不计提折旧、不产生折旧分录 |
| BO.BS 资产负债表—固定资产(1601)/无形资产(1701)/货币资金(1001) | 资产原值按取得时点增加 1601/1701 发生额（按法人公司汇总生成分录、各法人单体入账）；预付款与付款减少货币资金 1001 |
| BO.CF 现金流量表—CF-14 | 月度预付款额 + 月度付款额合计形成现金流出（CF-14 基数为预付款 + 付款，不取资产原值列），按法人公司分别列报，归入购建固定资产、无形资产和其他长期资产支付的现金；集团合并时各法人间不互抵 |

**关键编制规则**

- 资产原值按取得时点确认；预付款与付款是两个独立的付款度量，只驱动现金流，不与资产原值混同。
- 本表不计提折旧、不产生折旧分录：原值按法人公司、资产类别归集后汇入 BB.4.5（来源=手工新增）计提（下月折），再汇入 BB.4.X.A；资产类别=使用权资产的行（外部 BB.4.2.a 资本化租赁自动生成）与其它新增资产一样进入 BB.4.5 计提折旧（剩余年限(月数)=租赁期月数、残值率取 AA.9 默认 0%、启用月=租赁期起始月、原值=租赁负债初始），折旧经 BB.4.X.A 归集；该行本身只提供原值、用于资产卡片/统计与 BO.BS 1621 列报。
- CF-14 基数为月度预付款额 + 月度付款额（不取资产原值列），按法人公司分别列报；不含税口径，不处理增值税。

## ⑥ 财务报表项转换规则

**其他固定资产新增** `1~12月资产原值、1~12月预付款额、1~12月付款额`

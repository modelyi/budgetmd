## 第二部分 · 具体场景说明

### 01 设备代采购

#### 先看这三件事

| 事项 | 结论 |
| :--- | :--- |
| 业务实质 | 代采购服务提供方受托代买设备，只按净额法确认一笔代采购服务费（不赚差价，也不把自己垫付的采购本金算成购销流水）；设备只在接受方建卡 |
| 填报入口 / 实施落点 | 采购岗填“设备及无形资产采购（采购视角）”（BB.3.1.A/.B）；关联交易预算员补“设备及无形资产采购·关联交易视角”（BB.3.1.D）；通过“代采购资产查询表”“采购财务视角”和“增量资产折旧计算表”（BJ.C.e、BB.3.1.C、BB.4.5）核对建卡 |
| 三表和合并影响 | 接受方固定资产原值按 10,500 入账、到货月结清内部结算款、次月起按月提折旧，整笔 10,500 作为长期资产购建相关现金流；合并层冲固定资产原值加成 500，并按对外真实成本 10,000 口径抵消接受方多提折旧；税层面影响由财务人工判断，本方案不自动测算。 |

#### 在做什么

和原材料代采购同一套逻辑，标的换成机台仪器：接受方（使用公司）要设备，代采购服务提供方对外统一采购、签约、履约、垫资付款，设备调配给接受方使用；采购本金平价转过去，提供方只收代采购服务费。同样定性为受托代理。

一个关键分工：**设备卡只在使用方建**。提供方零持有、零折旧；接受方建卡、次月起提折旧。

#### 谁来填、用什么表

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 采购岗（下单主体） | “设备及无形资产采购（采购视角）”（BB.3.1.A/.B） | 填下单主体与关键度量：到货额 / 预付款 / 验收付款，负责对外下单、签约、付款 |
| 关联交易预算员 | “设备及无形资产采购·关联交易视角”（BB.3.1.D） | 补填受益主体；按下单主体与受益主体关联的法人识别跨法人代采购；加成比例取自 BAA.11，按规则计算到货额与加成款 |
| 财务岗 | “代采购资产查询表”和“采购财务视角”（BJ.C.e、BB.3.1.C） | 核对设备代采购明细与法人报表项，确认受益方资产原值 |
| 使用方（受益主体） | “增量资产折旧计算表”（BB.4.5，来源 = 代采购转入） | 建资产卡、次月起提折旧（提供方不建卡、不提折旧） |
| 参数层 | “关联交易加成比例”（BAA.11） | 财务部统一维护加成率，填报取数时按 BAA.11 取用，填报人不改 |

#### 预算入账规则

**A 单体报表项口径（代采购服务提供方）：**

形成（垫资本金与服务费分两笔写，本金不进收入）：
- 借：其他应收款—内部往来 10,000（代垫采购本金，平价转付接受方）
- 贷：货币资金 10,000（对外垫付供应商 = 预付款 + 验收付款）
- 借：其他应收款—内部往来 500（代采购服务费，向接受方收取）
- 贷：其他业务收入—内部往来 500（代采购服务费，净额法；垫资本金 10,000 不确认收入）

结算（到货月收到接受方内部结算款，只冲往来、不再影响损益）：
- 借：货币资金 10,500
- 贷：其他应收款—内部往来 10,500（本金 10,000 + 服务费 500 一并冲平，期末往来余额为 0）

**B 单体报表项口径（接受方 · 使用方）：**

形成（到货月建卡入账）：
- 借：固定资产 10,500（= 到货额 10,000 + 加成款 500）
- 贷：其他应付款—内部往来 10,500

结算（到货月一次付清内部结算款）：
- 借：其他应付款—内部往来 10,500
- 贷：货币资金 10,500（期末往来余额为 0）

折旧（次月起按月计提，设备场景区别于物料场景的关键一笔）：
- 借：销售费用 / 管理费用 / 研发费用（按设备用途归属，费用归属取“增量资产折旧计算表”BB.4.5 建卡信息；生产用途折旧经存货线结转，不直进损益）
- 贷：累计折旧（月折旧 = 原值 10,500 ÷ 折旧月数，参数取 AA.9；计提同时冲减固定资产净值，非付现成本、不产生现金流）

**集团合并抵销口径：**
- 借：其他应付款—内部往来 10,500；贷：其他应收款—内部往来 10,500（内部往来按对手方配对冲平；到货月已结清则两头余额均为 0）
- 借：其他业务收入—内部往来 500；贷：固定资产 500（A 侧服务费收入与 B 侧原值加成对冲，合并层固定资产原值只留对外真实采购成本 10,000）
- 折旧影响（预算口径，不逐月测算）：B 单体按 10,500 提折旧，合并层按对外真实成本 10,000，差额就是加成款 500 对应的折旧（按月 = 500 ÷ 折旧月数）。合并层随 B 的折旧进度同步抵消多提部分——借：累计折旧（多提部分）；贷：销售费用 / 管理费用 / 研发费用（多提部分的折旧费用，按 B 的费用归属对冲）。加成 500 与原值加成、折旧多提两头对齐，折旧提完后全额抵平，合并层固定资产净值始终只反映对外真实成本 10,000 口径。
- 税层面的合并抵销、递延所得税等由财务人工处理，不纳入本预算编制功能默认测算。

**付款假设（影响现金流）：** 接受方按到货结算、到货月一次付清「到货额 + 加成款」= 10,500；接受方支付给代采购服务提供方的整笔款项作为长期资产购建相关现金流。代采购服务提供方对外垫资（预付款 + 验收付款 = 10,000，购建长期资产支付的现金）属集团内部资金调度，合并层内部收付抵销后只保留对外供应商长期资产付款。

#### 实施避坑指南

**折旧卡只在使用方建**：提供方零持有、零折旧；两边都建卡，就会重复提折旧、资产和利润双双失真。受益方原值按「到货额 + 加成款」（不含税内部结算额 10,500）入账，加成款不要再额外加一遍。折旧自到货月的次月起计提，月折旧 = 原值 ÷ 折旧月数，非付现成本、不进现金流。

**垫资本金与服务费必须分两笔挂往来**：提供方对外垫付的 10,000 是代垫本金、只走「其他应收款—内部往来」，不能记成自己的采购或销售收入；服务费 500 单独计「其他业务收入—内部往来」。到货月接受方付清 10,500 后，提供方应收与接受方应付同时清零、1:1 对平；只写形成、不写结算，两边会一直挂着内部往来余额，合并层就轧不平。

### 02 原材料代采购（受托代理 · 净额法）

#### 先看这三件事

| 事项 | 结论 |
| :--- | :--- |
| 业务实质 | 代采购服务提供方受托统一采购并垫资，只按净额法确认一笔代采购服务费（不赚差价，也不把自己垫付的采购本金算成购销流水） |
| 填报入口 / 实施落点 | 采购岗填“物料类采购（采购视角）”（BB.3.3.A/.B）；财务岗补“物料类采购·关联交易视角”（BB.3.3.D）；通过“代采购物料查询表”和“采购财务视角”（BJ.C.a、BB.3.3.C）核对；接受方在“进销存预算表”（BB.3.X）承接转入 |
| 三表和合并影响 | 接受方按到货额 + 加成款入存货；合并层冲平内部往来，期末未领用加成冲减存货；税层面影响由财务人工判断，本方案不自动测算。 |

#### 在做什么
代采购服务提供方（下单主体关联的法人公司）对外统一下单、签约、履约、垫资付款，物资按需调拨到接受方入库，双方按月结算：采购本金平价转过去，提供方只收一笔代采购服务费。
提供方就是个代办：赚的是服务费、不是差价，垫出去的那笔采购本金也不算它自己的买卖流水。

#### 谁来填、用什么表

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 采购岗 | “物料类采购（采购视角）”（BB.3.3.A/.B） | 填下单主体与关键度量：到货额 / 预付款 / 验收付款，负责对外下单、签约、付款 |

#### 实施避坑指南

**代采购服务提供方严禁做总额收入**：提供方只确认 500 万元服务费；把垫资的 10,000 万元按买断记成自己的采购 + 销售流水，就是虚增营收，审计直接否定（提供方只是代办，法律与商业实质都是受托代理，不是买断自营）。到货额是平价、不含加成；加成款已按「到货额 × 加成比例」单独另算，不含税内部结算额 = 到货额 + 加成款，别再在到货额上重复加一遍加成。

**垫资本金与服务费必须分两笔挂往来**：提供方对外垫付的 10,000 是代垫本金、只走「其他应收款—内部往来」，不能记成自己的采购或销售收入；服务费 500 单独计「其他业务收入—内部往来」。到货月接受方付清 10,500 后，提供方应收与接受方应付同时清零、1:1 对平；只写形成、不写结算，两边会一直挂着内部往来余额，合并层就轧不平。

**存货场景只入存货，不建资产卡、不提折旧**：接受方按「到货额 + 加成款」入存货，只做存货与内部往来两笔；建卡提折旧是设备代采购（场景 01）的处理，物料代采购不适用，领用时才按物料类别结转成本或费用。

### 03 内部产品销售（自主制造购销 · 总额法）

#### 先看这三件事

| 事项 | 结论 |
| :--- | :--- |
| 业务实质 | 自产产品跨法人真买真卖，卖出方按完整内部售价确认收入并结转成本 |
| 填报入口 / 实施落点 | 供销业务岗在“内部销售预算”（BJ.C.g）登记；“关联交易加成比例”和“产品标准成本”（BAA.11、BAA.2）提供计价参数 |
| 三表和合并影响 | 单体按完整交易额出表；合并层按已对外销售 / 期末未售拆分，期末未售只冲减未实现加成；税层面影响由财务人工判断。 |

#### 在做什么

A（制造基地法人）有产线、有产品；B（销售公司或再加工法人）有客户、有订单。A 把自产产成品卖给 B，B 作半成品 / 原材料再加工后对外销售。

这是**真买真卖**（自主制造购销），不是代采购：A 按成本加成定价确认收入、结转成本；B 按内部售价接存货、对外卖。判定规则只有一条：供货方/卖出方法人与签约主体不是同一家法人（同一家内部移库，不算内部交易）。

#### 谁来填、用什么表

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 供销业务岗 | “内部销售预算”（BJ.C.g） | 逐笔登记买卖双方、交易类型（产成品销售）、入库类型（半成品/原材料）、数量与单位成本 |
| 财务岗（双方审核） | “内部销售预算”（BJ.C.g，审核）和“集团合并抵销工作底稿”（BO.ELIM） | 核对内部销售单价（单位成本 ×(1+加成)）与两端金额 1:1 一致 |
| 参数层 | “关联交易加成比例”和“产品标准成本”（BAA.11、BAA.2） | 提供成本与加成参数；加成比例取自 BAA.11，单位成本取自 BAA.2 |

#### 预算入账规则

**A 单体报表项口径（卖出方）：**

形成（真买真卖，按内部售价确认收入、按卖出方成本结转，收入与成本两边各计一笔）：
- 借：其他应收款—内部往来 10,500
- 贷：主营业务收入—内部往来 10,500（内部售价 = 单位成本 ×(1 + BAA.11 加成比例)）
- 借：主营业务成本—内部往来 10,000（结转卖出方成本；总额法，不按净额只认加成）
- 贷：存货 10,000（产成品出库）

结算（收到 B 内部结算款，只冲往来、不再影响损益）：
- 借：货币资金 10,500
- 贷：其他应收款—内部往来 10,500（期末往来余额为 0）

**B 单体报表项口径（买入方）：**

形成（按内部售价接存货入账）：
- 借：存货 10,500（按入库类型记原材料 / 半成品 / 产成品）
- 贷：其他应付款—内部往来 10,500

结算（结算月付清内部结算款；按月结算的按实际节奏）：
- 借：其他应付款—内部往来 10,500
- 贷：货币资金 10,500（期末往来余额为 0）

**集团合并抵销口径：**
- 借：其他应付款—内部往来 10,500；贷：其他应收款—内部往来 10,500（内部往来按对手方配对冲平；结算后两头余额均为 0）
- 已对外销售部分：借：主营业务收入—内部往来；贷：主营业务成本（按已实现内部售价冲减当期成本）

- 税层面的合并抵销、递延所得税等由财务人工处理，不纳入本预算编制功能默认测算。

### 04 内部物料销售（真实购销 · 总额法）

| 事项 | 结论 |

| 业务实质 | 内部物料跨法人真实购销，提供方按完整价销售，签约主体按含加成采购价进项目物料成本 |

#### 在做什么

物业持有公司（出租方）手里有厂房、办公区、工位；子公司（承租方）要地方办公、生产。按市场单价 × 面积算租金，加成按 BAA.11，按月收付结算。

本场景名称统一为**内部职场租赁**；资本化只是长租承租方的计量规则：租期超过 12 个月时，承租方确认「使用权资产 + 租赁负债」，按剩余租赁月数摊销并按折现率确认利息；12 个月及以内费用化场景本期不展开。

| :--- | :--- | :--- |
| 出租方（物业持有法人） | “内部职场租赁”（BB.4.2.b） | 填租赁标的、面积、市场单价，确认内部租金 |
| 承租方 | “内部职场租赁”（BB.4.2.b）登记 / “内部职场租赁·财务视角”（BB.4.2.b.1） | 填租赁期限；拆「使用权资产 + 租赁负债」，折旧进“增量资产折旧计算表”（BB.4.5）计提 |
| 财务岗 | “内部职场租赁·财务视角”和“集团合并抵销工作底稿”（BB.4.2.b.1、BO.ELIM） | 核对内部租金、加成款与合并抵销 |

#### 预算入账规则

**A 单体报表项口径（出租方）：**
- 借：其他应收款—内部往来 10,500
- 贷：其他业务收入—内部往来 10,500（内部租金 10,000 + 加成 500）

**B 单体报表项口径（承租方）：**
- 借：使用权资产（剩余租赁付款额折现值）
- 贷：租赁负债（剩余租赁付款额折现值；后续按月折旧进费用、利息进财务费用）

- 内部租金收入 10,500 与承租方按月计提的折旧、利息费用对冲，合并层只留出租方自有资产折旧
- 税层面影响由财务人工判断，本方案不自动测算。

### 07 内部资金借贷（本金往来 + 利息收支）

#### 先看这三件事

| 事项 | 结论 |
| :--- | :--- |
| 业务实质 | 集团资金中心与子公司之间短期拆借；本金是内部往来，利息是内部收支 |
| 填报入口 / 实施落点 | 资金管理岗在“内部借款预算表”（BJ.C.f）逐笔登记借款方向、本方法人、对手方法人、利率、期限和还本付息 |
| 三表和合并影响 | 本金只进往来，利息进当期收支；合并层本金、利息、现金流配对抵销；税层面影响由财务人工判断。 |

#### 在做什么

集团资金中心与子公司之间（或子公司相互之间）做短期资金拆借：借出方放款、借入方提款，按协议年利率按月计息，到期还本、按约定付息。这不是白用钱，利息要真金白银算清、付清。

#### 谁来填、用什么表

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 资金管理岗 | “内部借款预算表”（BJ.C.f） | 逐笔登记借款方向（借入/借出）、本方法人与对手方法人、利率、期限，按月填提款、还本、计提利息、实付利息 |
| 财务岗（双方审核） | “内部借款预算表”（BJ.C.f，审核）和“集团合并抵销工作底稿”（BO.ELIM） | 核对两端本金利息一致、配对抵销 |

#### 预算入账规则

**A 单体报表项口径（借出方）：**
- 借：其他应收款—内部往来 10,000（放款本金）
- 贷：货币资金 10,000
- 月收息：借：货币资金 ≈ 41.7；贷：其他业务收入—内部往来 ≈ 41.7

**B 单体报表项口径（借入方）：**
- 借：货币资金 10,000
- 贷：其他应付款—内部往来 10,000（提款本金）
- 月付息：借：财务费用 ≈ 41.7；贷：货币资金 ≈ 41.7

**集团合并抵销口径：**
- 借：其他应付款—内部往来 10,000；贷：其他应收款—内部往来 10,000（本金往来冲平）
- 借：其他业务收入—内部往来 ≈ 41.7；贷：财务费用 ≈ 41.7（利息一收一付对冲）
- 税层面影响由财务人工判断，本方案不自动测算。

#### 业务示例

| 项目 | 内容 |
| :--- | :--- |
| 示例输入 | 本金 10,000；年利率 5%；月利息 41.7（10,000 × 5% ÷ 12） |
| 业务结果 | 借出方其他应收款—内部往来 10,000、每月其他业务收入—内部往来 41.7；借入方其他应付款—内部往来 10,000、每月财务费用 41.7 |
| 实施核对 / 容易误解 | 本金只做往来，不进收入成本；利息一收一付当期对冲；税层面影响由财务人工判断，本方案不自动测算。 |

#### 三表怎么出（A 单体 / B 单体 / C 集团合并）

**A 单体怎么出（借出方）：**

| 三表 | 报表项（变动） | 怎么取数 |
| :--- | :--- | :--- |
| 利润表 | 其他业务收入—内部往来 +41.7/月 | BJ.C.f·当月计提利息（= 本金 × 年利率 ÷ 12） |
| 资产负债表 | 货币资金 −10,000（放款）、其他应收款—内部往来 +10,000 | BJ.C.f·当月新增 |
| 现金流量表 | 放款流出 −10,000、收息流入 +41.7/月、收本流入 +10,000（到期） | BJ.C.f·当月新增 / 当月实付利息 / 当月还本 |

**B 单体怎么出（借入方）：**

| 三表 | 报表项（变动） | 怎么取数 |
| :--- | :--- | :--- |
| 利润表 | 财务费用 +41.7/月 | BJ.C.f·当月计提利息 |
| 资产负债表 | 货币资金 +10,000（提款）、其他应付款—内部往来 +10,000 | BJ.C.f·当月新增 |
| 现金流量表 | 提款流入 +10,000、付息流出 −41.7/月、还本流出 −10,000（到期） | BJ.C.f·当月新增 / 当月实付利息 / 当月还本 |

**C 集团合并怎么出：**

| 三表 | 报表项（变动） | 怎么取数 |
| :--- | :--- | :--- |
| 利润表 | 其他业务收入—内部往来 −41.7、财务费用 −41.7 | BO.ELIM 第①类：利息一收一付对冲 |
| 资产负债表 | 内部往来发生额或结算前挂账 ±10,000，按对手方冲平 | BO.ELIM 第②类 |
| 现金流量表 | 放款/还本/付息收付双向对冲净 0 | BO.ELIM 第③类（利息当期对冲、无未实现利润） |

#### 实施避坑指南

**两头必须对得上**：借出方利息收入 = 借入方利息费用，本金一放一还逐笔对应；数字对不上，合并层就轧不平、出不了表。借入方取得的贷款服务进项税额不得抵扣；本方案默认内部借款按应税处理，集团如有统借统还等免税安排，另行调整。

### 08 二手资产转卖（处置收益 + 续提折旧）

#### 先看这三件事

| 事项 | 结论 |
| :--- | :--- |
| 业务实质 | 子公司之间转让已使用资产，卖方按处置处理，买方按转卖价入账并继续使用 |
| 填报入口 / 实施落点 | 资产管理岗填“资产转卖预算表”（BJ.C.d）；卖方填“资产处置预算表”（BB.4.6）；买方填“其他固定资产新增表”（BB.4.3），并在“增量资产折旧计算表”（BB.4.5）按剩余期限续提折旧 |
| 三表和合并影响 | 卖方确认处置收益 500 并在结算月收回转卖款；买方固定资产原值 10,500、次月起在剩余折旧期限内续提折旧；合并层抵销内部处置收益并冲减资产原值加成，再按集团原有成本基础抵消买方多提折旧；税层面影响由财务人工判断。 |

#### 在做什么

某子公司的旧设备、无形资产还在账上、已提过折旧，另一家子公司正好要用。走内部转卖：转卖价 = 账面净值 ×（1 + 加成率）；卖方转出资产、赚一笔处置收益（加成部分）；买方按转卖价入账、接着提折旧；转让款走内部划款。

#### 谁来填、用什么表

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 资产管理岗 | “资产转卖预算表”（BJ.C.d） | 逐笔登记买卖双方、资产类别、剩余折旧期限、账面净值；按规则计算加成收入与转卖价 |
| 卖方 | “资产处置预算表”（BB.4.6，处置方式 = 内部转卖） | 登记处置减少 |
| 买方 | “其他固定资产新增表”和“增量资产折旧计算表”（BB.4.3、BB.4.5） | 登记新增、建卡、剩余期限内续提折旧 |
| 财务岗 | “集团合并抵销工作底稿”（BO.ELIM） | 核对卖方处置收益与合并抵销 |
| 参数层 | “关联交易加成比例”（BAA.11，交易类型 = 资产转卖） | 加成比例取自 BAA.11；加成收入 = 账面净值 × 加成比例 |

#### 预算入账规则

**A 单体报表项口径（卖方）：**

形成（固定资产账面净值转出 + 加成分确认为内部处置收益）：
- 借：其他应收款—内部往来 10,500
- 贷：固定资产 10,000（账面净值转出）
- 贷：资产处置收益 500（= 账面净值 × BAA.11 加成比例）

结算（收到买方内部转卖款，只冲往来、不再影响损益）：
- 借：货币资金 10,500
- 贷：其他应收款—内部往来 10,500（期末往来余额为 0）

**B 单体报表项口径（买方）：**

形成（按转卖价入账）：
- 借：固定资产 10,500
- 贷：其他应付款—内部往来 10,500

结算（结算月付清内部转卖款）：
- 借：其他应付款—内部往来 10,500
- 贷：货币资金 10,500（期末往来余额为 0）

折旧（次月起按月计提，在剩余折旧期限内续提）：
- 借：销售费用 / 管理费用 / 研发费用（按资产用途归属，费用归属取“增量资产折旧计算表”BB.4.5 建卡信息；生产用途折旧经存货线结转，不直进损益）
- 贷：累计折旧（月折旧 = 入账原值 10,500 ÷ 剩余折旧月数，剩余期限取“资产转卖预算表”BJ.C.d 登记；计提同时冲减固定资产净值，非付现成本、不产生现金流）

**集团合并抵销口径：**
- 借：其他应付款—内部往来 10,500；贷：其他应收款—内部往来 10,500（内部往来按对手方配对冲平；结算后两头余额均为 0）
- 借：资产处置收益 500；贷：固定资产 500（冲减原值里的加成，合并层固定资产原值只留集团原有成本基础 10,000）
- 折旧影响（预算口径，不逐月测算）：买方单体按 10,500 续提折旧，合并层按集团原有成本基础 10,000，差额就是加成 500 对应的折旧（按月 = 500 ÷ 剩余折旧月数）。合并层随买方的折旧进度同步抵消多提部分——借：累计折旧（多提部分）；贷：销售费用 / 管理费用 / 研发费用（多提部分的折旧费用，按买方的费用归属对冲）。加成 500 与原值加成、折旧多提两头对齐，剩余期限内提完即全额抵平，合并层固定资产净值始终只反映集团原有成本基础 10,000 口径。
- 税层面的合并抵销、递延所得税等由财务人工处理，不纳入本预算编制功能默认测算。

## 附录 · 速查页（顾问上手用）

### A. 报表项落点三条通用规则

1. 只到报表项目行：不建新科目、不往下拆明细；内部交易的记号只有一个，就是在报表项后面加「—内部往来」。
2. 往来端固定两行：「其他应收款—内部往来」（提供方、借出方挂）、「其他应付款—内部往来」（接受方、借入方挂）；按对手方配对，按月结算。
3. 接受方按不含税内部结算额（到货额 + 加成款）入「存货」或「固定资产」；长期资产由使用方在“增量资产折旧计算表”（BB.4.5）建卡、次月起提折旧，提供方不建卡。

### B. 集团合并出表口径

- 公式：集团合并数 = 各单体汇总数 − BO.ELIM 集团合并抵销工作底稿的抵销数，直出合并利润表、资产负债表、现金流量表。
- 抵销六件事：
  1. 内部购销与费用对冲：提供方「收入—内部往来」与接受方「成本—内部往来」（或租金费用）等额对冲；
  2. 内部往来冲平：「其他应收款—内部往来」与「其他应付款—内部往来」按对手方配对、全额对冲；
  3. 内部现金流对冲：内部结算划款等额双向对冲，合并现金流只留对外真实收支；
  4. 存货未实现加成：期末没实现的产品、物料、代采购服务费加成，冲减存货；
  5. 长期资产加成与折旧：冲掉原值里的加成，说明后续折旧影响；
  6. 内部租赁专项：消掉承租方的内部「使用权资产」与「租赁负债」，还原出租方自有资产折旧。

> 本方案是预算编制功能，BO.ELIM 默认只处理内部收入/成本、内部往来、内部现金流、期末未实现内部加成对存货或资产原值的预算抵销。税层面的合并抵销、递延所得税等由财务人工处理，不纳入本预算编制功能默认测算。

### C. 实施管控三条

1. 两边金额必须相等：提供方结算额 = 接受方成本 / 资产入账原值，1:1 对得上；对不上就卡住、不许合并出表。
2. 按月结算：BS 中内部往来表示当月发生额或结算前挂账；如按月划款或资金池结清，单体期末余额为 0，合并层期末不留内部往来余额。
3. 增值税各自申报：内部交易是应税交易，卖方计销项、买方计进项（货物 13%、服务 6%、不动产租赁 9%、有形动产租赁 13%，税率取 AB.15）；增值税是价外税，不进存货、资产和成本的入账金额，统一在 BF.4 税金表集中测算。

#### 三、通用纪律

1. 科目颗粒度止于报表项目行：不新建报表项、不用明细科目码，内部交易的记号只有一个，就是在标准报表项后追加「—内部往来」。
2. 往来端固定两行：「其他应收款—内部往来」（给出去的一方挂）、「其他应付款—内部往来」（收进来的一方挂）。
3. 税层面的合并抵销、递延所得税等由财务人工处理，本方案不自动测算；BO.ELIM 默认只处理内部收入/成本、内部往来、内部现金流、期末未实现内部加成对存货或资产原值的预算抵销。

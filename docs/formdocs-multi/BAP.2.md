需求类型 2 类（表内行级维度、默认常规）：常规承载常规物料消耗，研发长期承载原独立的研发长期物料消耗需求汇总表（整表已并入本表）——合并后不再单设研发长期表，同一表内按 需求类型 区分。

领料用途 4 类：生产类进在制品「料」腿、研发类进研发费用、销售类进销售费用、管理类及其他进管理费用。

边界：本表不包括两类领料——服务领料归 BB.1.3（.d/.f）、自制设备领料归 BB.4.1.c；研发长期物料消耗需求已并入本表（需求类型=研发长期，物料类别固定「研发物料」）。

## ② 字段与值说明

| 字段 | 来源 | 说明 | 填报要求 |
| :--- | :--- | :--- | :--- |
| 预算项目 | AA.6 预算项目主数据 | 物料消耗归属的预算项目；领料用途可由预算项目属性自动映射带出（产品化项目→生产类、研发项目→研发类、销售项目→销售类、职能/公共平台项目→管理类及其他） | 必输；下拉选择 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 预算部门原则上明细到二级部门 | 必输；下拉选择；一般明细到二级部门 |
| 需求类型 | 本表录入 | 下拉枚举：常规 / 研发长期；默认「常规」。用于表内区分两类物料消耗需求——常规物料消耗，与原独立的研发长期物料消耗需求汇总表（整表已并入本表）承载的研发长期物料消耗；研发长期行的物料类别固定「研发物料」、领料用途为研发类 | 必输；下拉选择；下拉：常规 / 研发长期（默认常规）；表内区分常规与研发长期两类物料消耗需求 |
| 物料编码 | AA.11 物料主数据 | 消耗物料编码，从物料主数据选择（研发长期行必填、由物料名称按物料主数据带出）；常规物料消耗无编码时留空 | 选填；从 AA.11 物料主数据选择（研发长期行必填、由物料名称按物料主数据带出）；常规物料消耗无编码时留空 |
| 物料名称 | AA.11 物料主数据 | 消耗物料名称，从物料主数据选择 | 必输；从 AA.11 物料主数据选择（按物料编码带出） |
| 物料类别 | AB.9 存货物料类别字典 | 可选值：生产物料/研发物料/服务物料/专项储备/其他物料；与 BB.3.3 物料采购、BB.3.X 进销存品类同一口径，按物料类别归集消耗去向；需求类型=研发长期 的行固定「研发物料」（关联 AB.9）、不可修改 | 必输；下拉选择；关联 AB.9 存货物料类别字典（生产物料/研发物料/服务物料/专项储备/其他物料） |
| 领料用途 | 本表录入 | 可选值：研发类/销售类/管理类及其他（生产物料消耗无前置收集表，在 BB.3.X 在制品料行直接手工填报）；决定物料消耗去向（研发类→研发费用、销售类→销售费用、管理类及其他→管理费用），可由预算项目属性自动映射带出 | 必输；下拉选择；4 类：生产类/研发类/销售类/管理类及其他，决定物料消耗去向；可由预算项目的项目属性自动映射带出，无需人工逐行判断 |
| 月度消耗金额 | 本表录入 | 按月手工填报；全年合计=SUM(1~12月)；金额不含税、单位万元、精度 0.1 | 必输；手工填报 |
| 全年合计 | 本表公式 | =SUM(1~12月消耗金额) | 公式自动计算；全年合计 = SUM(1~12月) |
| 备注说明 | 本表录入 | 补充物料消耗的业务假设或特殊事项 | 选填；手工填报 |

## ④ 适用业务情形

**适用于**

- 各部门月度物料消耗金额汇总（需求类型：常规 / 研发长期 两类；领料用途：生产/研发/销售/管理及其他），是 BB.3.X 进销存出库与在制品领料的唯一取数来源（领料结转分录由 BB.3.X.b 领料与结转视图生成）；研发长期物料消耗需求（需求类型=研发长期、物料类别固定「研发物料」）为原独立的研发长期物料消耗需求汇总表整表并入本表后的行

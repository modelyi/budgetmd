## ② 字段与值说明

| 字段 | 来源 | 说明 | 填报要求 |
| :--- | :--- | :--- | :--- |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 研发长期物料消耗需求归属的预算部门，默认明细到二级部门 | 必输；下拉选择 |
| 物料编码 | AA.11 物料主数据 | 研发长期消耗物料编码，从物料主数据选择 | 必输；手工填报 |
| 物料名称 | AA.11 物料主数据 | 按物料编码自动带出 | 系统带出 |
| 物料类别 | AB.9 存货物料类别字典 | 固定值「研发物料」：本表仅承载研发长期物料消耗需求，物料类别恒为研发物料，不可修改 | 系统带出；固定「研发物料」，关联 AB.9；本表仅承载研发长期物料消耗需求 |
| 月度消耗金额 | 本表录入 | 按月手工填报；全年合计=SUM(1~12月)；金额不含税、单位万元、精度 0.1 | 必输；手工填报 |
| 全年合计 | 本表公式 | =SUM(1~12月消耗金额) | 公式自动计算；全年合计 = SUM(1~12月) |
| 备注说明 | 本表录入 | 补充研发长期物料消耗的业务假设或特殊事项 | 选填；手工填报 |

## ④ 适用业务情形

**适用于**

- 研发长期物料消耗需求汇总（表样占位；前置模块未开发，暂无数据来源）

**不适用于**

- 生产/销售/管理类物料消耗（属 BAP.2）

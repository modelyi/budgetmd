## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 抵销事项编号 | 系统编号 | 一行一个抵销事项；按 ELIM-01 起连续编号 |
| 抵销事项 | 本表 | 抵销事项名称（如「物料代采购内部销售与成本对冲」「借款利息收支对冲」「期末存货未实现利润抵销」等） |
| 抵销类型 | 本表枚举 | 五类抵销类型：①内部购销对冲 ②内部往来对冲 ③内部现金流对冲 ④未实现利润-存货 ⑤未实现利润-长期资产 |
| 影响利润表项目 | 会计规则引擎 | 合并利润表（BO.PL）对应的调整项目（如 营业收入/营业成本/管理费用/财务费用/资产处置收益） |
| 影响资产负债表项目 | 会计规则引擎 | 合并资产负债表（BO.BS）对应的调整项目（如 存货/固定资产/使用权资产/其他应收款/其他应付款） |
| 影响现金流量表项目 | 会计规则引擎 | 合并现金流量表（BO.CF）对应的调整项目（如 销售收现/采购付现/投资收付/筹资收付） |
| 1~12月抵销金额 | 系统自动取数 | 1~12月各月抵销金额（不含税，万元）；负数代表调减合并数（抵销内部虚增），正数代表调增 |
| 全年合计 | 本表公式 | =SUM(1~12月抵销金额) |
| 取数来源 | 本表 | 数据来源表单与字段（如 BJ.C.a.monthlyDeliveryAmount），支持点击跳转 |
| 说明 | 本表录入 | 抵销规则补充说明 |

## ④ 适用业务情形

**适用于**

- 集团财务部编制合并预算、核对各子公司抵销明细与平衡性复核
- 出具供管理层与外部审计查验的合并抵销工作底稿

**不适用于**

- 子公司单体预算编制与日常核算
- 对外部独立第三方的正常商业往来

## ⑤ 预算编制视角：数据关系总结

合并抵销工作底稿承上启下：汇总各内部交易表单（BJ.C 各表、BB.3.X、BB.4.5）自动生成抵销事项，直连 BO.PL / BO.BS / BO.CF 作为合并三表的“内部抵销”数据源。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 代采购物料查询表 | BJ.C.a | 月度到货额、加成款 | 驱动物料代采内部购销与往来抵销 |
| 代采购资产查询表 | BJ.C.e | 月度到货额、加成款 | 驱动设备代采内部购销与往来抵销 |
| 资产转卖预算表 | BJ.C.d | 月度加成收入、转卖价 | 驱动二手资产转让加成收益抵销 |
| 内部借款预算表 | BJ.C.f | 借款本金、利息收付 | 驱动借贷往来与利息收支对冲 |
| 内部销售预算表 | BJ.C.g | 内部销售额 | 驱动内部产品购销等额对冲 |
| 内部职场租赁 | BB.4.2.b | 月度内部租金 | 驱动内部租金与使用权资产抵销 |
| 进销存预算表 | BB.3.X | 内部转入加成额 | 驱动存货未实现加成抵销 |
| 增量资产折旧计算表 | BB.4.5 | 内部加成折旧额 | 驱动长期资产加成折旧分期抵销 |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.PL 合并利润表 | 提供利润表“内部抵销”调整列数值 |
| BO.BS 合并资产负债表 | 提供资产负债表“内部抵销”调整列数值 |
| BO.CF 合并现金流量表 | 提供现金流量表“内部抵销”调整列数值 |

**关键编制规则**

- 底稿各行与合并三表调整列一一对应。
- 抵销分录均可追溯至前端业务表单行。

## ⑥ 财务报表项转换规则

本表共用口径：合并抵销底稿作为编制合并三表调整数的依据；递延所得税等税层面影响由财务人工测算、系统不自动处理。

**报表取数**

| 度量/报表项 | 取数字段 | 损益表 PL | 资产负债表 BS | 现金流量表 CF |
| :--- | :--- | :--- | :--- | :--- |
| ① 内部购销与费用对冲 | BO.ELIM·月度抵销金额（①内部购销对冲） | 冲减合并营业收入与营业成本、内部管理费用：内部收入与内部成本 / 费用等额对冲、不影响合并净利润 | —（本类只做损益对冲） | —（现金口径由③内部现金流对冲处理） |
| ② 内部往来冲平 | BO.ELIM·月度抵销金额（②内部往来对冲） | —（不影响损益） | 冲减「其他应收款—内部往来」与「其他应付款—内部往来」内部往来余额、配对归零 | —（不影响现金流） |
| ③ 内部现金流对冲 | BO.ELIM·月度抵销金额（③内部现金流对冲） | —（不影响损益） | —（不影响资产负债表项目） | 冲减内部结算现金流入与流出，合并现金流只留外部真实发生额 |
| ④ 存货未实现加成 | BO.ELIM·月度抵销金额（④未实现利润-存货） | 冲减随内部销售结转进营业成本的未实现加成，合并后只保留内部供应商真实成本 | 调减存货中的未实现加成 | —（不影响现金流） |
| ⑤ 长期资产加成·折旧与内部租赁 | BO.ELIM·月度抵销金额（⑤未实现利润-长期资产） | 冲减长期资产内部加成及其折旧、内部租赁收入与内部租赁利息，合并后只保留出租方自有物业的原始折旧 | 调减固定资产、使用权资产与存货中的未实现加成；使用权资产与租赁负债在合并层整体消除 | —（现金口径由③内部现金流对冲处理） |

**科目（报表项）入账**

| 度量/报表项 | 借 | 贷 |
| :--- | :--- | :--- |
| ① 内部购销与费用对冲 | 营业收入（内部销售、内部加成、内部租金与内部利息） | 营业成本、管理费用（内部费用承担方） |
| ② 内部往来冲平 | 其他应付款—内部往来 | 其他应收款—内部往来 |
| ③ 内部现金流对冲 | 经营活动现金流入小计（内部结算收款侧冲减） | 经营活动现金流出小计（内部结算付款侧冲减） |
| ④ 存货未实现加成 | 营业成本（已对外销售部分中的未实现加成） | 存货（期末存货中的未实现加成） |
| ⑤ 长期资产加成·折旧与内部租赁 | 营业收入（内部加成与内部租金收入）、资产处置收益（内部转卖加成）、财务费用（内部租赁利息） | 固定资产、使用权资产、存货（未实现加成）、租赁负债（合并层整体消除） |

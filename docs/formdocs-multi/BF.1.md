## ② 字段与值说明

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 法人公司 | AA.2 法人组织架构 | 投资主体（出资法人），投资及现金流按该法人归集 |
| 被投资企业所属行业 | AB.2 国资委行业字典 | 保留行业分类 |
| 投资对象 |  |  |
| 投资区域 | 本表录入 | 市内/境内市外/海外 |
| 项目启动时间 (年月) | 本表录入 | 按项目计划填报年月 |
| 预计结束时间 (年月) | 本表录入 | 按项目计划填报年月 |
| 项目投资总额 | 本表录入 | 项目整体投资计划，可能包括资本金以外资金；不得无条件等于己方出资额+合伙人投入资本 |
| 己方投资比例 | 本表录入 | 按投资协议填报；不强制等于己方出资额占资本金或总投资的比例 |
| 己方出资额 | 本表录入 | 我司约定出资金额，与本年实际计划付款分开 |
| 合伙人投入资本 | 本表录入 | 其他股东/合伙人约定投入的资本，不代表项目全部资金来源 |
| 至上年末累计投入 | 本表录入 | 我司截至上年末累计投入金额 |
| 累计投资金额 | 本表公式 | 截至本年末=至上年末累计投入+全年投资金额 |
| 本年累计分红/利息 | 本表公式 | =SUM(1~12月分红/利息收现)，不含以前年度；原列改为本年口径，不新增历史数据入口 |
| 持股比例-股权投 | 本表录入 | 预计本年末按协议持有的股权比例 |
| 预计每年收益 | 本表录入 | 预计归属于我司的年度收益（非被投企业全额利润）；不强行等于当年现金分红 |
| 资本回收周期 | 本表公式 | 单位年。仅在稳定可收现收益假设下作简化静态参考：己方出资额÷预计每年收益（1位小数）；收益≤0或假设不适用时留空/不适用，不得为0年或除零 |
| 月度投资金额 | 本表录入 | 按月填报我司投资付款额，单位万元 |
| 分红/利息收现 | 本表录入 | 按预计收现月份填报我司收款额；收益确认与收现不默认相等 |
| 全年投资合计 | 本表公式 | =SUM(1~12月投资金额) |
| 全年分红/利息收现合计 | 本表公式 | =SUM(1~12月分红/利息收现) |

## ④ 适用业务情形

**适用于**

- 对外股权投资的年度预算，含投资金额、收益预测

**不适用于**

- 金融工具类投融资（属 BF.3）
- 关联方之间的内部交易（属 BJ.C）

## ⑤ 预算编制视角：数据关系总结

股权投资预算是对外股权投资的年度预算账，按投资对象登记月度投资金额与分红/利息收现，全年投资合计公式汇总；区分于金融工具类投融资（BF.3）。

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.PL 利润表—投资收益 | 以归属于我司的预计年度收益为预算依据；不以当年现金分红直接替代，期间及收现差额经既有 BJ.A 调整入口处理且不重复计入 |
| BO.BS 资产负债表—长期股权投资 | 月度投资金额 → 长期股权投资 (+)；分红/利息收现 → 货币资金 (+) |
| BO.CF 现金流量表—投资活动 | 投资金额 → 投资支付的现金 (+)；分红/利息收现 → 取得投资收益收到的现金 (+) |

## ⑥ 财务报表项转换规则

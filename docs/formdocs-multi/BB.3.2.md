## ④ 适用业务情形

**适用于**

- 基建项目采购预算，按预算项目、预算部门跟踪验收额与付款额

**不适用于**

- 设备类资本性支出（属 BB.3.1）
- 自制类在建工程（属 BB.4.1）

## ⑤ 预算编制视角：数据关系总结

基建工程采购预算（土建/装修/土地购买），按月填报验收额与付款额，转固金额按月汇总自基建转固明细表；验收额 → 在建工程 1604 发生额增加（工程验收确认在建工程原值），付款额 → 仅驱动 CF-14 现金流出（不构成在建工程原值），转固金额 → 1604 转出、1601 固定资产原值增加并进 BB.4.X（次月起提折旧）；期初金额构成 BO.BS 1604 在建工程年初余额。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 资产类别及折旧参数 | AA.9 | 资产类别 | 基建转固明细表资产类别对齐 AA.9，转固资产按 AA.9 参数下月起提折旧进入 BB.4.X |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BB.4.X 资本性支出汇总表 | 验收转固金额达到可使用状态后按房屋建筑物/辅助设施小类归集入 BB.4.X（次月起提折旧） |
| BO.BS 资产负债表—在建工程(1604)/固定资产(1601) | 期初金额与 BB.4.1.a 期初金额共同构成 1604 年初余额；验收额按工程验收确认 1604 发生额增加（借 1604 / 贷 2202）；转固按 BB.3.2.b 转固月份使 1604 转出、1601 原值增加（两侧同额） |
| BO.CF 现金流量表—CF-14 | 基建付款额 → 购建固定资产支付的现金（投资活动现金流出）；付款额不构成在建工程原值 |

## ⑥ 财务报表项转换规则

**基建验收（在建工程按验收额确认）** `1~12月验收额`

- 取数说明：取自本表月度验收额手工填报值；工程验收确认在建工程原值（借 1604 / 贷 2202）；按本表「法人公司」列直接归属法人，按法人公司汇总生成分录
- 损益表 PL：—（验收确认在建工程，不进损益；折旧经 BB.4.X 计提后进费用）
- 资产负债表 BS：在建工程 1604 (+)（按验收额确认原值）；应付账款 2202 (+)
- 现金流量表 CF：—（工程验收不直接产生现金流）
- 科目影响：借：在建工程(1604)；贷：应付账款(2202)
- 其他备注：验收额是本表对 BO.BS 1604 在建工程原值的确认口径；付款额只驱动 CF-14（购建固定资产支付的现金），不构成在建工程原值；转固金额按 BB.3.2.b 转固明细表把 1604 转入 1601。三者不得互相引用为金额来源。期初金额 BB.3.2.openingAmount 与 BB.4.1.a.openingAmount 共同构成 BO.BS 1604 在建工程年初余额。本表不处理增值税，验收额均为不含税口径。

**基建付款** `1~12月付款额`

- 取数说明：取自本表月度工程付款额手工填报值；付款额只驱动 CF-14（购建固定资产支付的现金），不构成在建工程原值（1604 增加以验收额确认）；按本表「法人公司」列直接归属法人，按法人公司汇总生成付款分录与 CF-14 现金流出
- 损益表 PL：—
- 资产负债表 BS：货币资金(1001) (−)；应付账款 2202 (−)
- 现金流量表 CF：投资活动现金流出：CF-14 (+)
- 科目影响：借：应付账款(2202)；贷：货币资金(1001)
- 其他备注：含建筑安装工程预付款与质保金支付节点，归入 CF-14。本表不处理增值税，付款额均为不含税口径。付款分录与验收、转固分录均按本表「法人公司」列分别汇总到各法人单体报表，集团合并时各法人间不得互抵。验收额为 1604 确认口径、付款额为 CF-14 度量、转固额为 1601 来源。

**基建验收转固** `1~12月转固金额（公式）`

- 取数说明：转固金额为公式字段（按月汇总基建转固明细表 BB.3.2.b 同月转固原值）；转固按 BB.3.2.b 的转固月份把 1604 转入 1601，转固金额同时构成 1604 在建工程减少与 1601 固定资产增加（两侧同额）；转固后按转固月份进入 BB.4.X 在建工程来源，次月起提折旧；转固原值按本表「法人公司」列归属，按法人公司汇总生成转固分录（借固定资产贷在建工程）

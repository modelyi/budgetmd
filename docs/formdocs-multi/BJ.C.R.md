## ④ 适用业务情形

**适用于**

- 编制集团合并预算三表时，跨法人内部交易（采购、销售、租赁、资产、资金）的抵销配置与系统执行
- 集团财务与审计团队对内部交易公允性、抵销底稿两端平衡性的复核
- 实施顾问依据合并抵销口径配置合并抵销模板与校验规则

**不适用于**

- 子公司单体预算编制（单体预算在各业务表独立填报与核算）
- 同一法人内部部门或车间之间的物料领用与调拨
- 对外部供应商与客户的正常商业往来

## ⑤ 预算编制视角：数据关系总结

本表为合并抵销核心规则总纲，规范各内部交易表单的数据口径，驱动 BO.ELIM 逐行生成五类抵销事项（ELIM-01~05），最终生成对外披露的集团合并三表；递延所得税等税层面影响由财务人工测算，系统不自动处理。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 代采购物料查询表 | BJ.C.a | 到货额、加成款 | 驱动物料内部购销与存货加成抵销 |
| 代采购资产查询表 | BJ.C.e | 到货额、加成款 | 驱动设备内部购销与资产加成折旧抵销 |
| 资产转卖预算表 | BJ.C.d | 账面净值、加成收入 | 驱动二手资产处置收益与资产增值抵销 |
| 内部借款预算表 | BJ.C.f | 本金、利息收付 | 驱动借贷本金往来与利息收支对冲 |
| 内部产品销售预算表 | BJ.C.g | 销售收入、销售成本 | 驱动内部产品购销等额对冲 |
| 内部职场租赁 | BB.4.2.b | 内部租金、加成款 | 驱动内部租金收支对冲与使用权资产抵销 |
| 进销存预算表 | BB.3.X | 期末内部加成余额变动 | 提供存货未实现加成变动额 |
| 增量资产折旧计算表 | BB.4.5 | 内部加成卡片折旧额 | 提供资产各月折旧中的加成额 |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.ELIM 集团合并抵销工作底稿 | 按规则逐行生成全集团合并抵销事项明细（ELIM-01~05） |
| BO.PL 合并利润表 | 抵减内部购销收入与成本费用，消除未实现内部加成影响的损益 |
| BO.BS 合并资产负债表 | 内部往来轧差清零，存货与资产中的未实现加成恢复原始成本 |
| BO.CF 合并现金流量表 | 内部结算资金对冲，只留对外真实收支 |

## ⑥ 财务报表项转换规则

本表共用口径：抵销规则用于避免内部交易虚增合并营业收入与成本：跨法人内部债权债务全额消除、合并报表只留对外应收应付；内部资金划转不构成对外现金流入流出；期末存货未实现加成消除、对外售出时自动冲回；长期资产折旧按原始成本计提，不因内部加成虚增资产或费用。

**报表取数**

| 度量/报表项 | 取数字段 | 损益表 PL | 资产负债表 BS | 现金流量表 CF |
| :--- | :--- | :--- | :--- | :--- |
| 内部购销对冲（利润表） | BJ.C·月度交易额 / 加成款 | 等额抵销：调减“营业收入—内部往来”，同额调减“营业成本—内部往来”，对合并净利润无净影响 | —（损益项目对冲，不直接影响资产负债） | —（现金流随内部结算收付对冲） |
| 内部往来配对轧差（资产负债表） | BJ.C·期末内部往来余额 | —（往来科目对冲，不影响损益） | 配对清零：冲销“其他应收款—内部往来”与“其他应付款—内部往来”，合并资产负债表余额为 0 | —（往来余额对冲，不产生当期现金流） |
| 内部结算现金流对冲（现金流量表） | BJ.C·月度内部结算实收实付资金额 | —（资金划拨，不影响损益） | —（现金收付已体现在各单体货币资金中） | 等额对冲：收款方现金流入与付款方现金流出等额互抵，合并现金流净额为 0 |
| 期末存货未实现加成消除 | BB.3.X·期末内部加成余额变动 | 调减当期营业成本—内部往来 | 调减存货账面价值，还原为原始对外采购成本 | —（权责发生制还原，不影响现金流） |
| 长期资产加成原值与折旧消除 | BB.4.5·内部加成资产卡片各月计提折旧 | 调减合并折旧费用（消除加成部分的折旧分摊） | 调减固定资产 / 使用权资产原值（消除加成）与累计折旧，按原始账面净值延续 | —（非付现费用调减，不产生现金流） |

**科目（报表项）入账**

| 度量/报表项 | 借 | 贷 |
| :--- | :--- | :--- |
| 内部购销对冲（利润表） | 营业收入—内部往来 | 营业成本—内部往来 / 存货 / 固定资产 |
| 内部往来配对轧差（资产负债表） | 其他应付款—内部往来 | 其他应收款—内部往来 |
| 内部结算现金流对冲（现金流量表） | — | — |
| 期末存货未实现加成消除 | 营业成本—内部往来 | 存货 |
| 长期资产加成原值与折旧消除 | 资产处置收益 / 营业收入（购入期·冲减内部加成收入） | 固定资产 / 使用权资产（购入期·冲减资产中的内部加成） |

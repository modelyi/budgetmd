# 对外软硬件销售（实施培训手册）

> 一句话讲透本质：**硬件有实物、走存货；软件没实物、直接转成本——两条成本路径不能混。**

把自研的硬件设备与配套软件卖给集团外客户，一笔合同走完全程：签约 → 生产完工 → 发货／部署 → 客户验收 → 回款。收入按月度填报值直取（「验收一次性／直线法」只是业务标记，不是系统自动分摊规则），成本与收入同期配比。

## ① 在做什么（业务通俗说）

卖的是两样东西，走的是两条成本路径：

- **硬件（整机设备）**：有实物——生产完工先入库（进存货）；卖出去时从存货出库、结转销售成本；
- **软件（配套软件）**：没有实物、不入存货——按「销量 × 标准成本」当期直接结转成本。

收入与收款一律按「签约主体（法人公司）」归集，不做比例拆分；销售订单不登记内部供货关系（跨法人的内部供货属于内部关联交易，见 AA 方案）。

## ② 谁来填、用什么表（业务与财务分工）

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 业务岗（销售/合同管理） | BB.1.1 销售合同签约额预算 | 填签约额预期——它驱动订单与销量安排 |
| 业务岗（销售） | BB.1.2.a 软硬件销售 | 填销量、单价（不含税）、预收与回款；存量订单与本年新增合并在这一张表 |
| 财务岗 | BB.1.2.c 财务视角 | 字段由系统带出，财务只补一项：预计销售成本 |
| 假设参数层 | BAA.2 产品标准成本 | 由财务与产品部门拍板维护，各表自动带出，填报人不改标准参数 |

## ③ 怎么算账（核心公式与极简算例）

**核心公式（系统自动，不用手算）：**

- 收入 = 销量 × 单价（不含税）
- 成本 = 销量 × 产品标准成本（BAA.2）
- 现金流 = 预收 + 验收回款，按合同节奏按月填报

**极简算例**（数字换成实际值照样成立）：

| 项目 | 金额 | 怎么来的 |
| :--- | :--- | :--- |
| 收入 | 200 万元 | 2 台 × 100 万元/台 |
| 成本 | 120 万元 | 2 台 × 60 万元/台（标准成本） |
| 回款 | 150 万元 | 预收 50 万元 + 验收回款 100 万元 |
| 应收 | 50 万元 | 收入 200 − 回款 150 |

金额一律不含税；增值税不进这里的账，统一在 BF.4 税金表集中测算。

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 营业收入（分硬件销售、软件销售两条业务线） | 销量 × 单价按月汇总 |
| 利润表 | 营业成本 | 硬件随存货出库结转 + 软件当期直接结转 |
| 资产负债表 | 应收账款 | 收入 − 回款 |
| 资产负债表 | 存货 | 产成品完工入库增加、销售出库减少（软件不入存货） |
| 资产负债表 | 货币资金 | 预收 + 回款流入 |
| 现金流量表 | 销售商品、提供劳务收到的现金（CF-01） | 预收 + 验收回款，系统校验 |

## ⑤ 实施避坑指南

**硬件、软件的成本路径别走反**——硬件有实物，必须「先进存货、销售出库再结转成本」；软件无实物，按当期销量 × 标准成本直接转成本。把软件也塞进存货、或者让硬件不走存货凭空转成本，存货余额和当期成本两头都会错。

**收入按月度填报值直取**——「验收一次性／直线法」只是业务标记；不要把它当成系统的自动分摊规则去手工重算收入，更不要跨月自行拆收入。

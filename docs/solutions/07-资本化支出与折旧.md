# 资本化支出与折旧（实施培训手册）

> 一句话讲透本质：**用超一年、够门槛的支出才建卡；当月新增、下月起提，折旧再按比例摊进各条费用。**

本年支出中具有长期使用价值的部分形成资产：从购置、建设、租赁或内部转入开始，到按月计提折旧进入成本费用为止。来源包括外购设备与无形资产、基建工程、自制设备、职场租赁资本化、代采购资产转入、二手资产受让六类。

## ① 在做什么（业务通俗说）

买来、建来的东西算不算「资产」，就看三条：**用超过 1 年 + 金额达到门槛（AA.9）+ 形成长期资产**。达到的，建卡、逐月提折旧；达不到的（日常维修、低值易耗品、12 个月以内的租赁），当期直接费用化，不进资产。

资产来源有六路：外购设备与无形资产、基建工程、自制设备、职场租赁资本化、代采购资产转入、二手资产受让（代采资产、二手受让的跨法人细节见 AA 方案）。

一句话分工：**谁使用谁建卡**——代采购的设备在受益方建卡、提供方不建卡；二手受让由买方接着提折旧。

## ③ 怎么算账（核心公式与极简算例）

**核心公式：**

- 每月折旧额 = 原值 ×（1 − 残值率）÷ 剩余年限（月数）
- 折旧惯例「下月折」：当月新增资产，下月起提
- 折旧按 BAA.9.b 比例拆入制造、研发、管理、销售四大费用

**极简算例**（一台设备）：

| 项目 | 数 | 怎么来的 |
| :--- | :--- | :--- |
| 原值 | 120 万元 | 采购到货不含税价（代采转入按含加成到货额） |
| 残值率 | 5% | AA.9 参数 |
| 折旧年限 | 10 年 | AA.9 参数 |
| 月折旧 | 0.95 万元/月 | 120 × 95% ÷ 120 个月 |
| 当年计提 | 10.45 万元 | 当月新增 → 下月起提，提 11 个月 |

折旧的去处：按 BAA.9.b 拆分——进制造的那份走存货线，随销售结转；进研发、管理、销售的那份直接进当期费用。购建付现在采购付现环节一次流出（投资活动），折旧本身不动现金。

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 销售费用、管理费用、研发费用（各自含折旧与摊销） | 按 BAA.9.b 拆入的费用折旧；使用权资产折旧及相关财务费用单列 |
| 资产负债表 | 固定资产、无形资产 | 原值增加、折旧逐月累积 |
| 资产负债表 | 在建工程 | 基建/自制投入增加，转固后转出 |
| 资产负债表 | 使用权资产、租赁负债 | 超过 12 个月的租赁 |
| 现金流量表 | 购建固定资产、无形资产和其他长期资产支付的现金 | 购建时一次流出（投资活动）；折旧不产生现金流 |

## ⑤ 实施避坑指南

**「下月折」不能提前**——当月新增的资产当月不提折旧、下月起提；提前提一个月，全年折旧、各条费用、存货成本全部偏。

**资本化判定两头都要防**——日常维修、低值易耗、12 个月及以内租赁不能建卡（建了资产虚增、费用少记）；反过来，够门槛的也别漏建卡（漏了费用虚增、资产少记）。判定线就一条：用超 1 年 + 达到 AA.9 门槛。

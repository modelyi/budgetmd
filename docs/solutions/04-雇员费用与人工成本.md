# 雇员费用与人工成本（实施培训手册）

> 一句话讲透本质：**全口径先计提、再按实际去处「搬家」——搬的是位置，不是金额；同一批人工全集团只算一次。**

全集团薪酬预算由 HR 统一编制：按「法人 × 部门 × 费用项目」逐月计提销售、管理、研发、制造四类人工，并填报实际发放。人事视角是全口径人工费用；之后按人员实际投入方向重分类——交付技术服务的人工进服务成本，投入自制设备的人工进在建工程。

## ① 在做什么（业务通俗说）

人工这笔钱有两本账要同时看：

- **人事视角（全口径）**：全集团每月一共要发多少人、多少钱——销售多少、管理多少、研发多少、制造多少，一分不少地先计提；
- **财务视角（重分类后）**：钱是同一笔钱，但「人实际在哪儿干活」决定它最后落在哪里：在车间干活 → 随产品走（制造费用）；被派去客户现场做服务 → 进服务成本；被派去造设备（自制设备） → 进在建工程（先当资产，不损当期利润）。

关键一句话：**重分类是「搬家」，不是「再记一笔」**——人工只在 BB.5.1 计提一次、付现只走一次。

## ② 谁来填、用什么表（业务与财务分工）

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| HR 岗 | BB.5.1 雇员费用编制/导入 · 人事视角 | 按「法人 × 部门 × 费用项目」逐月计提（销售/管理/研发/制造），并填实际发放 |
| 财务岗 | BB.5.1 · 财务视角 | 做重分类：服务人工、资本化人工从原费用等额冲减后单列 |

| 工程表（自动） | BB.4.1.b 自制设备人工投入明细 | 资本化人工的来源数据 |
| 假设参数层 | BAA.3 工时标准成本 | 拍板维护，服务人工结转按它计价 |

## ③ 怎么算账（核心公式与极简算例）

**核心公式：**

- 计提 = 按「法人 × 部门 × 费用项目」逐月汇总（销售 + 管理 + 研发 + 制造四类）
- 服务人工成本 = 工时 × BAA.3 工时标准成本 → 从原费用等额冲减，单列进营业成本
- 资本化人工 = 自制设备投入的人工 → 从原费用冲减，转进在建工程
- 付现 = 实际发放（CF-06），只走一次

**极简算例**（某法人某月）：

| 环节 | 金额 | 说明 |
| :--- | :--- | :--- |
| 计提 | 200 万元 | 制造 80 + 研发 50 + 管理 40 + 销售 30 |
| 制造 80 万元 | 走存货线 | 随完工、销售结转营业成本，不在当期费用直接列示 |
| 转服务成本 | 20 万元 | 服务项目人工，按部门费用属性从原费用冲减，单列进营业成本 |
| 转在建工程 | 30 万元 | 自制设备投入的资本化人工，从原费用冲减后转进在建工程 |
| 期间费用余 | 70 万元 | 销售 30 + 研发 50 + 管理 40 − 转出 50（示例中两笔重分类均出自研发/管理费用） |
| 实际发放 | 180 万元 | 付现口径 → CF-06，只走这一笔 |

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 销售费用、管理费用、研发费用 | 计提数 − 转出的两类人工 |
| 利润表 | 营业成本（服务直接人工） | 服务人工成本单列 |
| 资产负债表 | 应付职工薪酬 | 计提增加、发放减少 |
| 资产负债表 | 在建工程 | 资本化人工转入 |
| 现金流量表 | 支付给职工以及为职工支付的现金（CF-06） | 实际发放 |

两个口径差异记牢：**制造费用人工不在利润表直接出现**——它随完工、销售一路走存货，最后从营业成本里出来；薪酬按法人分别归集，集团合并时各法人之间不互抵。

## ⑤ 实施避坑指南

**同一批人工绝不算两遍**——财务视角的「冲减 + 单列」是费用换位置：总额不变、应付职工薪酬只在 BB.5.1 计提一次、发薪付现只走一次。在 BB.5.1 之外又计提一遍，人工成本直接翻倍。

**别漏资本化人工**——投入自制设备的工时如果不从费用里转进在建工程，就会沉淀在当期费用里：设备成本少一块、当期利润虚减一块。

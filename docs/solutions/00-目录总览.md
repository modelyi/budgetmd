## 二、预算编制为什么分成五层

打个直观的比方：全面预算像盖楼，五层从下往上叠，**下面一层没定，上面一层就没法算到底**。

| 层级 | 管什么 | 涉及表单 | 大白话 |
| :--- | :--- | :--- | :--- |
| ① 基础数据 | 全系统的「公共语言」 | AA / AB / AM | 法人、组织、产品、客户、物料、项目等主数据与各类字典——所有表引用的都是同一套名字，不会各报各的 |
| ② 假设参数 | 全系统的「标尺」 | BA / BAA | 编制前提、产品标准成本、工时费率、关联交易加成比例、税率与附加比率、付款节奏——标准定一次，全系统共用 |
| ③ 业务预算 | 业务部门报「生意怎么做」 | BB.1 销售 / BB.2 生产 / BB.3 采购 / BB.4 资本化 / BB.5 费用与资金 | 卖多少、产多少、买多少、投多少、花多少——业务量都在这层，金额一律不含税 |
| ④ 财务预算 | 财务把业务数「翻译」成财务口径 | BF 投融资与税金 / BJ.C 关联交易 | 投融资与税金在这里集中测算；跨法人的内部交易单独登记、加成按 BAA.11 测算 |
| ⑤ 合并与三表 | 收口出表 | BO.ELIM / BO.PL / BO.BS / BO.CF | 各单体汇总数 − BO.ELIM 抵销数 = 集团合并数，出具利润表、资产负债表、现金流量表 |

为什么非得这么分？三句话：

1. **各填各的，责任清楚**——业务岗只管「生意量」（卖几台、干多少活），财务岗只管「财务口径」（成本、税、抵销）；哪层出问题，一眼能看出是谁的事；
2. **标准只定一次**——标准成本、工时费率、税率这些「标尺」都在第②层拍板，下面所有表自动引用：改一次、全系统同步，不会出现两张表两个标准；
3. **越往上越自动**——③ 层往上全是「汇总 + 换算 + 抵销」，不是重新填一遍——所以上游数据什么时候改，上面看到的就是什么时候的新数。

## 三、上游一改、下游自动算（五层的联动关系）

五层之间的箭头（① → ② → … → ⑤）就是取数方向：**上游数据一改，下游自动跟着变。**

走一个例子就明白了——销售把某产品的全年销量从 1,000 台调成 1,200 台：

1. **③ 销售表**：收入 = 1,200 × 单价，自动变大；回款按合同节奏跟着更新；
2. **③ 生产表**：排产看销量安排，产量跟着调整；
3. **③ 采购表**：物料需求由排产推出来，采购量跟着变；
4. **⑤ 存货与成本**：完工入库、销售出库按新量走，营业成本随出库结转；
5. **⑤ 三表**：利润表的收入和成本、资产负债表的存货和应收、现金流量表的回款——全部自动刷新。

中间没有一处需要人工重算。落到日常填报就是一句话：**你只管填好自己那一层；上游一改，下游自动算。**

## 四、三个贯穿全系统的机制

1. **双视角**：销售、采购等业务表按「业务填报 + 财务视角」组织——业务岗专注报量报价，财务岗在同一张表上补齐成本与核算口径；
2. **法人归属**：每一行数据都归集到具体的法人公司，单体报表按法人出数；集团合并数由各法人汇总后抵销得出；
3. **关联交易**：跨法人的代采购、内部购销（产品/物料/人工）、内部租赁、资金借贷、资产转卖等业务，统一登记、由合并层抵销（详见独立页签「T5BB 关联交易专项方案说明」）。

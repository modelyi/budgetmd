# 全面预算编制系统——财务三表取数规则与勾稽手册

> 适用范围：企业集团全面预算编制系统
> 金额口径：全部不含税，万元单位，0.1 万元精度（四舍五入）
> 表样口径：BO.PL 全年合计 + 1~12 月；BO.BS 年初(期初)/发生(本期发生额)/调整/期末(=年初+发生+调整) 四列，不展开到月；BO.CF 本年累计一列（全年现金流合计，流量口径），不展开到月

## 1. 三表勾稽总则

### 1.1 三表关系

| 勾稽方向 | 规则 |
|---|---|
| 利润表 → 资产负债表 | 净利润扣除预计分红后，滚入未分配利润 |
| 现金流量表 → 资产负债表 | 期末现金及现金等价物余额 = 资产负债表货币资金 |
| 资产负债表恒等式 | 资产总计 = 负债合计 + 所有者权益合计 |

| 科目编码 | 报表项目 | 取数规则 | 数据来源 |

| 6001 | 一、营业收入 | = 6001.1 主营业务收入 + 6001.2 其他业务收入 | 公式 |

### 5.19 BJ.C.d 资产转卖预算表

> 定位：集团内资产转卖的关联交易台账与唯一取数源。口径 = 账面价值平移 + 关联交易加成；不创造科目，只用现有报表项目 1001 货币资金 / 1601 固定资产净值 / 6115 资产处置收益。

**表样（45 列，两行制标准时间度量列）：**
- **Row 0（维度与时间分组）**：固定业务维度 6 列（`卖方(法人)`｜`买方(法人)`｜`资产描述`｜`资产类别`｜`加成比例%(BAA.11 带出)`｜`剩余折旧期限(月)`）+ 时间分组大表头（`【全年合计】`（跨3列）+ `1月~12月`（各跨3列））；

**关键口径与折旧计算：**
- **月度填报与转让时点**：发生月份直接在对应月份的度量子列填报，全年合计自动求和，彻底移除原孤立的「转让月份」列；
- **定价公式**：
  - **加成收入** ＝ 账面净值 × 加成比例%，即卖方确认的资产处置加成收益（6115），集团合并层全额抵销；

### 5.24 使用权资产折旧摊销·实施配置说明

> 定位：把**使用权资产（1621）折旧**从「算什么」落到「实施怎么配」——本小节是配置实施清单，只固化已定口径，不新增报表项目行、不新增科目、不改表样。内部职场租赁走 BB.4.2.b / BB.4.2.b.1、外部职场租赁走 BB.4.2.a / BB.4.2.a.1（见 §5.17、§5.23），两条线在本节合为同一套配置说明。

**1) 输入来源：两张测算表只出租赁负债与现金流，折旧统一由 BB.4.5 计提**

- 资本化合同在 **BB.4.2.b.1 内部职场租赁·财务视角** 与 **BB.4.2.a.1 外部职场租赁·财务视角** 中只算**租赁负债与现金流**：**租赁负债初始**、**使用权资产原值**（= 租赁负债初始）、**剩余租赁月数**、**月度利息**、**月度本金偿付**、**租赁付款额**；折旧不再在这两张表计提。
- 折旧在 **BB.4.5 增量资产折旧计算表**计提：由这两张表带出原值（= 租赁负债初始）与剩余年限(月数)（= 租赁期月数），残值率取 AA.9 默认 0%、启用月=租赁期起始月，与其它新增资产同链路按「下月折」计提后经 BB.4.X.A 归集；**不另建使用权资产台账/卡片台账**。存量折旧一律走 ERP 导入的 BB.4.4，不建跨年滚存逻辑。

**2) 计算公式（唯一口径）**

| 项 | 口径 |
|---|---|
| 每月折旧额 | 使用权资产原值 ×(1−残值率) ÷剩余年限(月数)；折旧参数取 AA.9 默认账簿的「固定资产-使用权资产」行（在 BB.4.5 计提） |
| 折旧方法 | 年限平均法（取 AA.9 默认账簿的「固定资产-使用权资产」行） |
| 剩余年限(月数) | 使用权资产=租赁期月数（=剩余租赁月数，按合同租期带出、动态不设固定月数）；普通资产=AA.9 默认资产账簿的折旧年限(月)（AA.9 已按「月」维护，如 120 个月） |
| 残值率 | 取 AA.9 默认账簿的「固定资产-使用权资产」行（当前 0%；直线法、按租赁期摊销） |
| 计提起点 | 下月折——自租赁期起始月的**次月**起计提 |
| 本年折旧月数 | 当年落在租期内的月数 |

按「承租方预算部门 → 部门费用性质（AM.2）」拆分：

**⑤ 按行生成分录与取数公式（实施口径）**

计算单元＝本表每一笔融资行（一行一笔）：先按「融资类型」落档（计息负债档 / 融资租赁档 / 应收变现档 / 表外额度档 / 外汇档）、按「融资主体(法人公司)」定归属法人，再对该笔融资逐月执行 1~12 月下列公式。记号：`+=` / `−=` 表示在该报表行原值上增加 / 减少（与「报表项编码 (+)/(−)」同义），`[月]` 表示该笔融资当月的字段值，金额单位万元、0.1 万元精度。

1. **期初承接（不生成分录）**：短期借款 2001 年初 = Σ 各笔「已有期初净额」按档位与期限落行；长期借款 2501 年初 = Σ 各笔「已有期初净额」中属长期（剩余期限 >12 个月）部分。不含应付未付利息。
2. **提款**（月度新增融资金额[月] > 0）：到期月份 = 到期时间（maturityDate）已填 → 取 maturityDate；未填 → 期初时点（预算年度 1 月 1 日）+ 期限（term）推算；剩余期限（月数）= 到期月份 − 当前月份。货币资金 1001 `+=` 当月新增融资金额；负债侧按档位与剩余期限路由——计息负债档且剩余期限 ≤12 个月 → 短期借款 2001 `+=` 当月新增融资金额；剩余期限 >12 个月 → 长期借款 2501 `+=` 当月新增融资金额；应收变现档（XYZ-05 贴现 / XYZ-13 应收账款保理 / XYZ-20 贴现，本年度按有追索简化）→ 短期借款 2001 `+=` 当月新增融资金额；内部借款（XYZ-16）不在本表编制（见 §5.27 BJ.C.f 内部借款预算表：借出方 1221.1、借入方 2241.1）；表外额度档与外汇档不生成负债分录。CF-18 `+=` 当月新增融资金额（表外额度档 / 外汇档除外；内部借款 XYZ-16 不在本表、见 §5.27）。
3. **还本**（月度偿还本金[月] > 0）：按该笔提款时落定的负债行反向冲减（提款落 2001 的冲 2001、落 2501 的冲 2501）`−=` 当月减少，不做二次期限判断；货币资金 1001 `−=` 当月减少；CF-20 `+=` 当月减少（本金与利息不得混入同一现金流行）。
4. **利息计提**（月度计提利息[月] > 0）：融资费用类型 = 费用化 → 财务费用 6604.1 `+=` 当月计提；= 资本化 → 在建工程 1604 `+=` 当月计提；对方科目 应付账款 2202 `+=` 当月计提（两类同额；按当月计提发生额归集，不按应付未付余额逐月求和）。
5. **利息付现**（月度实付利息[月] > 0）：应付账款 2202 `−=` 当月实付利息；货币资金 1001 `−=` 当月实付利息；CF-21 `+=` 当月实付利息（付现不再确认费用）。
6. **融资费用**（融资费用[月] > 0）：财务费用 6604 `+=` 当月融资费用；货币资金 1001 `−=` 当月融资费用（经营类手续费按现行口径不单列现金流行）。费用构成与分月归属仍为 A1.5 待确认项，确认前保留原字段、不自动重复加总。
7. **流动性重分类（长期借款档每笔）**：到期月份 = 到期时间（maturityDate）已填 → 取 maturityDate；未填 → 期初时点（预算年度 1 月 1 日）+ 期限（term）推算；若 到期月份落到预算年度内（≤ 预算年度末）且该笔落在 2501 → 一次性生成 长期借款 2501 `−=` 该笔一年内到期本金、一年内到期的非流动负债 2504 `+=` 同额；金额 = 该笔「已有期初净额」中属长期且当年内到期部分 − 当年已列「减少」。不产生现金流、不进 PL、负债合计不变，不得与 CF-20 还本（真实付现）混用。
8. **档位特例**：融资租赁（XYZ-08）——租期开始月 使用权资产 1621 `=` 租赁负债 2602 `=` 租赁付款额折现值；每月利息 6604.1 `+=` 当月利息、租赁负债 2602 `+=` 同额；本金偿付 租赁负债 2602 `−=` 当月本金、CF-22.1 `+=` 当月本金；利息付现 CF-21 `+=` 当月利息付现；折旧不在本表（由 BB.4.5 计提、经 BB.4.X.A 归集）。表外额度档（担保 / 抵质押 / 开票 / 信用证 / 保函 / 信贷证明）——无分录，仅授信占用登记，手续费按第 6 条。外汇档——即期（XYZ-1501）无分录（仅货币资金 1001 内部币种转换、总额不变）；远期（XYZ-1502）/ 利率掉期（XYZ-1503）损益按第 6 条进 6604。
9. **汇总与出表**：各笔分录按 融资主体(法人公司) + 月份 汇总 → 该法人单体 PL/BS/CF 对应行；集团合并层：本表（外部/银行类融资）直接加总、不抵销；内部借款的 1221.1 / 2241.1 配对互抵见 §5.27；BF.3.d 融资预算汇总表不生成分录（仅汇总展示与勾稽）。

**③ 按行生成分录与取数公式（实施口径）**

计算单元＝本表每一行（一行＝一笔内部借款）＋ 月份[1..12]：先按「借款方向」定分录路由、按「本方法人」定归属法人，再逐月执行下列公式。记号：`+=` / `−=` 表示在该报表行原值上增加 / 减少（与「报表项编码 (+)/(−)」同义），`[月]` 表示该行当月的字段值，金额单位万元、0.1 万元精度。

1. **借入方提款**（当月新增[月] > 0）：货币资金 1001 `+=` 当月新增；其他应付款-内部往来 2241.1 `+=` 当月新增；CF-18 `+=` 当月新增（单体口径计入，集团合并层与借出方 CF-22.1 配对互抵）。
2. **借入方还本**（当月还本[月] > 0）：其他应付款-内部往来 2241.1 `−=` 当月还本；货币资金 1001 `−=` 当月还本；CF-20 `+=` 当月还本（本金与利息不得混入同一现金流行）。
3. **借入方利息计提**（当月计提利息[月] > 0）：财务费用 6604.1 `+=` 当月计提利息；其他应付款-内部往来 2241.1 `+=` 当月计提利息（不产生现金流、不进 CF）。
4. **借入方利息付现**（当月实付利息[月] > 0）：其他应付款-内部往来 2241.1 `−=` 当月实付利息；货币资金 1001 `−=` 当月实付利息；CF-21 `+=` 当月实付利息。
5. **借出方放款**（当月新增[月] > 0）：其他应收款-内部往来 1221.1 `+=` 当月新增；货币资金 1001 `−=` 当月新增；CF-22.1 `+=` 当月新增。
6. **借出方收本**（当月还本[月] > 0）：其他应收款-内部往来 1221.1 `−=` 当月还本；货币资金 1001 `+=` 当月还本；CF-19.2 `+=` 当月还本。
7. **借出方收息**（当月计提利息[月] > 0＝收息确认；当月实付利息[月] > 0＝当月实收利息）：计提——其他业务收入-内部往来 6001.2 `+=` 当月计提利息、其他应收款-内部往来 1221.1 `+=` 当月计提利息；收现——其他应收款-内部往来 1221.1 `−=` 当月实收利息、货币资金 1001 `+=` 当月实收利息、CF-19.2 `+=` 当月实收利息。
8. **融资费用**（融资费用[月] > 0）：财务费用 6604 `+=` 当月融资费用；货币资金 1001 `−=` 当月融资费用。
9. **汇总与出表**：各笔分录按 本方法人 + 月份 汇总 → 该法人单体 PL/BS/CF 对应行；本表不经 BF.3.d 融资预算汇总表汇总、也不并入 BF.3.d 的汇总范围。

**④ 配对互抵（集团合并层）**：各法人单体分别入账、集团合并数 = 各法人加总；集团合并层只按「本方法人 + 对手方法人」配对（借入方行 ↔ 借出方行、两行金额等额），互抵项逐组对应——其他应收款-内部往来 1221.1 ↔ 其他应付款-内部往来 2241.1；其他业务收入-内部往来 6001.2 ↔ 财务费用 6604.1（利息收支）；CF-18（借入方提款）↔ CF-22.1（借出方放款）；CF-20/CF-21（借入方还本付息）↔ CF-19.2（借出方收本收息）。合并不做单边抵销、集团层不留内部往来与内部利息痕迹。

**落点**：本节 ①~④ 与调研页 **A1.4.a 事件卡（code=BJ.C.f，9 张）**、**BJ.C.f 子表页⑥财务报表项转换规则（9 张事件卡＋末条「按行生成分录规则（实施公式）」）**同源同文，三处一致、不重复登记。

## 7. 精度与校验规则

### 7.1 金额精度

- 所有派生金额统一按 0.1 万元精度舍入（四舍五入）

### 7.2 月度尾差归集

- 前 11 个月按权重舍入到 0.1 万元，12 月 = max(0, 年度总额 − 前 11 月合计)，尾差归集至 12 月，保证月度合计 = 年度总额

### 7.3 勾稽校验

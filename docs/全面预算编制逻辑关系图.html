现金流量表（BO.CF）

  • 本年累计（流量口径）
  • 期末货币资金与 BO.BS 勾稽
勾稽：CF 期末现金 = BS 货币资金
复核要点（全年闭环）： ① 收入链：销量×单价 → 收入 → BO.PL；成本链：标准成本 → 进销存转出 → 营业成本，两条链只各计一次； ② 存货：年初+采购入库+完工入库−对外转出−消耗 = 期末，内部领用转在制品不改变集团存货总额； ③ 往来：预收/预付有期初、发生、收付、结转、期末五段，期末=年初+发生+调整； ④ 现金：合同负债/应收余额变化与 CF 收付一致，预收结转不重复计收入； ⑤ 合并：BO.ELIM 只做内部购销、内部往来、内部现金流、存货未实现加成、长期资产未实现加成五类抵销；递延所得税等税层面影响由财务人工测算，系统不自动处理； ⑥ 三表勾稽：PL 净利润 ↔ BS 未分配利润变动；CF 期末现金 ↔ BS 货币资金；BS 资产=负债+权益。

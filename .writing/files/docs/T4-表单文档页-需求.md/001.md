# T4 页签替换：表单文档页（需求与边界）

> 需求来源：用户指令「T4 按同样要求修改」
> 记录时间：2026-10-11
> 承接与替代：本条承接并替代 `docs/T3A-表单文档页-需求.md` §5 与 `docs/T3B-表单文档页-需求.md` §5 中「T4 页签不改」的边界；T1 总览、T3A / T3B 页签自身不受影响（页面与 37 / 43 篇文档保持现状），两版其余条款继续有效。

## 1. 目标

T4 页签（key `master`，标签「T4 基础静态数据」，groups AA / AB / AM，原由 `src/components/ResearchSummaryView.tsx` 以 multi 模式渲染 AA / AB / AM 三组基础静态数据表单）
改为**直接显示 `docs/formdocs-master/*.md` 这批表单文档**，不再使用 ResearchSummaryView 渲染。

- 文档共 **29 篇 = AA 11 + AB 16 + AM 2**（T4 菜单注册全量）；
- 内容一律由 XML 文字源逐字生成（T3A / T3B 同款生成链路）：不润色、不改口径、不改表样；
- 页签 key 与标签不变（`master` / 「T4 基础静态数据」）。

## 2. 参照实现（照搬 T3A / T3B，不新造轮子）

T3A「表单文档页」与 T3B「多主体编制套表」已完成的三件套即为本页参照基准：

- 组件 `src/components/FormDocsView.tsx`（左侧目录 + 右侧 ByteMD Viewer 阅览；已参数化：文档集 / 会话记忆键 / 文档源目录）；
- 数据源 `src/data/pages/formDocsMarkdown.ts`（T3A 37 篇）、`src/data/pages/formDocsMarkdownMulti.ts`（T3B 43 篇），共用装配件 `src/data/pages/formDocsShared.ts`；
- 生成脚本 `scripts/generateT3aFormDocs.ts`（XML 文字源 → 表单文档；现有范围 `--scope t3a | multi`）。

T4 照此结构落地，三处对应改动：

1. **组件复用**：`FormDocsView` 参数化实例——T3A 不传参（渲染与现状一致）、T3B 沿用现有传参（现状不变）、T4 新增第三个实例（文档集 / 会话记忆键 / 文档源目录三参数）；不复制组件。
2. **数据源**：新建 `src/data/pages/formDocsMarkdownMaster.ts` 读 `docs/formdocs-master/*.md`（`import.meta.glob` 打包期内联），导出 `formDocsMaster`；解析与装配复用 `formDocsShared.ts`——共享件增加「组序参数」：T3A / T3B 组序 `BA / BB / BF / BO` 不变，T4 组序 `AA / AB / AM`。
3. **生成脚本**：`scripts/generateT3aFormDocs.ts` 扩为三范围——缺省（不带 `--scope`）行为与现状一致（仍生成 `docs/formdocs/` 37 篇）；`--scope multi` 行为与现状一致（仍生成 `docs/formdocs-multi/` 43 篇）；新增 `--scope t4` 生成 29 篇至 `docs/formdocs-master/`。

## 3. 页面构成

- **左侧目录**：按 AA / AB / AM 三组归组（组序 AA→AB→AM；对应菜单组「AA 基础主数据」11 篇、「AB 业务字典」16 篇、「AM 勾稽与映射」2 篇，合计 29 篇）；条目显示「表单编码 + 表单名」，编码与表单名解析自文档首个 `# 编码 名称` 标题，解析不到时回退文件名。
- **右侧正文**：ByteMD Viewer 渲染当前选中文档的 Markdown 全文（GFM），标题、段落、表样按文档原样呈现；底部提供「上一篇 / 下一篇」翻页。
- **默认文档**：进入页签默认打开第一篇（AA.1）；用 sessionStorage 记住当前文档（整页刷新后续显），键 `budgetdemo:t4-doc:v1`——与 T3A 页签（`budgetdemo:t3a-doc:v1`）、T3B 页签（`budgetdemo:t3b-doc:v1`）各自独立，互不串扰。
- 顶部「Markdown 编辑」按钮在本页保持不可用（只读阅览、无编辑入口），与 T3A / T3B 页签一致。

## 4. 渲染与样式（复用 T3A / T3B 同款）

- 文档内嵌的 `<style>…</style>` 块在**渲染前剥离**（沿用同一数据源剥离逻辑）；样式统一由应用样式表提供，避免样式块被当正文显示。
- 表格样式沿用 `src/index.css` 的 `.t3a-doc-view` 作用域规则（T4 正文容器沿用同一类名）：表头深蓝底白字、单元格边框、表样单元格不换行、数值右对齐、表样隔行浅底。**不得**给全局 `table` / `th` / `td` 加样式（会影响其他页签）。
- 宽表横向滚动条常显、可见（既有 `::-webkit-scrollbar` 规则原样沿用、不另起一份：高 10px、滑块 `#94a3b8`、轨道 `#eef2f7`）；应用内用标准横向滚动，不用「滚动条置顶」等翻转技巧。
- 不改名 `.t3a-*` 样式类（避免波及 T3A / T3B 既有 80 篇文档与 `index.css`）。
- 深色模式下沿用现状基底，不新增深色适配（与 T3A / T3B 表现一致）。
- 呈现约定（沿用 T3A / T3B 已定）：同类**纯呈现层**的可用性问题（滚动条、列宽、对齐、间距、字号）直接改，不必逐项征求确认；涉及**内容、口径、表样结构**的变更仍需用户拍板。

## 5. 明确不做（边界）

- 不改表样 / 字段 / 口径内容：纯转换，内容由 XML 文字源逐字决定。
- 不改 T3A（37 篇）/ T3B（43 篇）既有文档内容；不改 T1 / T3A / T3B / T5 / T6~T9 任何页签与既有组件；T3A / T3B 页签渲染保持现状。
- 不提供「在线编辑 / 保存回盘」：这批 Markdown 由生成脚本产出，手改会被覆盖；页面无导出入口。
- 不做导出与打包：不跑 `build` / `build:spa`、不更新 `spa.html`（用户点名时才做）。
- 不装依赖；不删 `ResearchSummaryView.tsx`（T1 总览仍在使用）。
- 本机无版本控制（无 `.git`），不做任何 git 操作。
- 不改 `AGENTS.md`（系统保护文件，需用户批准；本次不动）。

## 6. 与 T3B 的差异点（T4 专属）

1. **组序 AA→AB→AM（T4 专属）**：目录组序为 AA 基础主数据 → AB 业务字典 → AM 勾稽与映射（T3A / T3B 为 BA→BB→BF→BO）；数据源按 T4 组序装配（共享件以「组序参数」区分），页面呈现以此序为准，不得出现其他组。
2. **无隐藏集差异**：T4 全量即 29 篇（AA 11 + AB 16 + AM 2）——不存在 T3B 那种「T3A 清单 + 多主体专属表单」的差异集，也无子表级隐藏 / 恢复项；29 篇即 T4 菜单注册全量，生成清单与页面目录一一对应。
3. **多子表表单（与 T3A / T3B 同构，非差异）**：AA.1（2 段：预算年度主数据 / 预算期间日历）、AA.2（2 段：法人组织架构主数据 / 法人组织架构图）、AA.3（3 段：统一科目总表 / 费用明细科目 / 科目编码规则表）表样分段连排、字段按子表分节——与 T3A（BAA.6 / BAA.7）同机制，属预期结构。
4. **清单与文档集边界**：29 篇逐条列于文末附录（已与 `MENU_GROUP_DEFS` 逐条核对），无 T3B 式「★ 多主体专属」星标分类；AA / AB / AM 与 T3A / T3B 文档清单无交集，三个页签文档集与浏览记忆键（`t3a` / `t3b` / `t4`）彼此独立、互不串扰。

## 7. 验收

验收沿用 T3A / T3B 同款流程——执行与验收分离、逐门禁、真实渲染＋截图；按下列门禁逐条执行，全部门禁通过前不报「完成」。

- **执行与验收分离**：落地执行 ＝ 文档处理 subagent；浏览器验证 / 财务专家核验 / doc-UAT 均由独立于执行方的角色出具结论，执行方不自证；
- **逐门禁验收**：① 机械校验（执行方自测，供复核：29 篇计数与清单一致、抽样逐字比对通过、T3A / T3B 既有 37 / 43 篇零变化、`tsc` 0 error）→ ② 浏览器验证（独立·只读·截图：目录 29 篇按 AA / AB / AM = 11 / 16 / 2 归组、默认首篇、点击切换与整页刷新续显、三个页签浏览记忆互不串扰、表样样式同款、T3A / T3B 回归）→ ③ 财务专家核验（转换保真：内容逐字取自 XML 未被误改；重点篇目 AA.11、AB.11、AB.12、AM.1）→ ④ doc-UAT（真实渲染＋截图，逐条核验）；

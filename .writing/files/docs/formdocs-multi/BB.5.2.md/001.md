## 表概述

经营费用转换表：由 BAP.1(BA.5)×BAA.8 计算得出的各法人公司经营费用转换结果，部门编至二级部门、默认带出部门费用性质（研发→6603、管理→6602、销售→6601、制造→1405），含研发/管理/销售/制造四项，跨部门项目部门可留空；纯展示不可编辑，现金流支出等于计提数。分录：6601/6602/6603 对 2202（制造费用性质按科目归入 1405 结转进在制品、不直接进损益），付现 2202 对 1001，按月驱动经营活动现金流出 CF-07。本表不按面积公摊房租/物业，只承载其余经营费用：外部职场租赁由 BB.4.2.a（费用化）与 BB.4.2.a.1（资本化）带出，内部场地租赁由 BB.4.2.b 带出，不与两类租赁重复取数。按法人编制。

## ③ 关键规则要点

**BB.5.2 经营费用转换结果表**

- 纯计算展示，不可手工编辑。维度=法人公司、项目、部门、部门费用性质、预算科目（按部门费用性质自动带出：研发费用→6603、管理费用→6602、销售费用→6601、制造费用→1405）；度量=全年合计(4子列)+1~12月(每月4子列)，两行制表头共57列。
- 各月表项分为4个子度量：研发费用、管理费用、销售费用、制造费用；其中制造费用改按产品成本法处理——结转进在制品（存货），不再直接进损益表，随在制品完工→产成品→销售才进营业成本。
- 部门与性质层级：这里的部门编到二级部门；"部门费用性质"默认来自于二级部门与费用性质的映射字典（AM.2）。二级/三级部门维护费用属性映射，一级部门不维护。
- 项目归属规则：有的项目不归属具体部门（跨部门/集团级项目），在此类场景下，"部门"与"部门费用性质"不必填（非必填，允许留空）。
- 计算与现金流规则：系统根据 BAP.1(BA.5).月度金额 × BAA.8.法人公司拆分比例 自动计算出各法人公司的费用金额；由于源头表 BAP.1(BA.5) 属于外部模块不直接影响现金流，因此由本表（BB.5.2）直接根据月度费用金额驱动经营活动现金流出（现金流支出等于计提数，按月全额付现）。
- 租赁类费用的来源不在本表按面积公摊：外部职场租赁的租金/物业由 BB.4.2.a 外部职场租赁（费用化合同，按用途归 6601/6602/6603）与 BB.4.2.a.1 外部职场租赁·财务视角（资本化合同）带出；内部场地租赁由 BB.4.2.b 内部职场租赁带出。本表只承载其余经营费用，不与两类租赁重复取数。

## ④ 适用业务情形

**适用于**

- 由 BAP.1(BA.5)×BAA.8 计算的各法人经营费用转换结果展示（销售/管理/研发/制造四项）

**不适用于**

- 费用明细填报（属 BA.5/外部系统）
- 外部职场租赁租金/物业（由 BB.4.2.a/BB.4.2.a.1 带出）与内部场地租赁（由 BB.4.2.b 带出）——两类租赁不在本表按面积公摊

## ⑤ 预算编制视角：数据关系总结

经营费用转换结果表是把外部费用预算模块（BAP.1/BA.5）的费用按法人拆分比例转换得到的各法人经营费用结果表，纯计算展示、不可编辑；研发/管理/销售三项费用直接进损益，制造费用结转进在制品（存货）不进损益，并按月全额驱动经营现金流出。

**数据来源（上游）**

| 来源表 | 编码 | 取数字段 | 关系说明 |
| :--- | :--- | :--- | :--- |
| 费用预算汇总表 | BA.5 | 月度费用金额 | 源头费用数据；按「月度金额 × BAA.8 法人占比」自动计算各法人×项目×部门月度费用 |
| 经营费用转换比例表 | BAA.8 | 法人公司占比 | 按法人公司拆分比例拆分到各法人 |
| 部门属性映射表 | AM.2 | 部门费用性质 | 按部门自动带出费用性质，决定预算科目映射（6601/6602/6603/1405） |

**输出影响（下游）**

| 目标报表 | 取数路径 |
| :--- | :--- |
| BO.PL 利润表—销售/管理/研发费用 | 销售→6601、管理→6602、研发→6603 (+)；制造费用不进损益，结转存货 |
| BB.3.X 进销存预算—在制品「费」腿 | 制造费用项金额作为在制品-费转入数（与 BB.4.X.A 并列，两处不得重叠取数） |
| BO.CF 现金流量表—CF-07 | 支付其他与经营活动有关的现金 (+)；现金流支出等于计提数 |
| BO.BS 资产负债表—其他应付款 | 费用计提→应付账款(2202) (+)；付现→货币资金 (−) |

**关键编制规则**

- 外部职场租赁的租金/物业来源不在本表按面积公摊：费用化合同由 BB.4.2.a 外部职场租赁带出（按用途归 6601/6602/6603）、资本化合同由 BB.4.2.a.1 外部职场租赁·财务视角带出；内部场地租赁由 BB.4.2.b 内部职场租赁带出。本表只承载其余经营费用，不与两类租赁重复取数。

## ⑥ 财务报表项转换规则

**经营费用发生与付现** `各部门费用性质月度金额（研发/管理/销售/制造）`

- 取数说明：BAP.1(BA.5).月度金额 × BAA.8.法人公司占比（按部门费用性质匹配）→ 各法人×项目×部门月度费用金额；现金流支出等于计提数
- 损益表 PL：销售/管理/研发费用→6601/6602/6603 (+)；制造费用→结转进在制品（存货），不直接进损益
- 资产负债表 BS：制造费用→存货（在制品 1405）(+)；销售/管理/研发费用→应付账款(2202) (+)
- 现金流量表 CF：经营活动现金流出：支付其他与经营活动有关的现金 CF-07 (+)（直接根据本表月度金额按月驱动现金流出；源头BAP.1(BA.5)为外部模块不影响现金流）
- 科目影响：销售费用(6601xx)/管理费用(6602xx)/研发费用(6603xx)/存货(1405)—非人工明细 (+)；应付账款/预提费用(2202) (+)。付现：应付账款(2202) (−)；货币资金(1001) (−)
- 其他备注：本表不处理增值税，均为不含税口径；部门费用属性默认自动取自 AM.2 部门属性映射表（按部门带出）；二级/三级部门维护费用属性映射，一级部门不维护；无具体归属部门的项目需手工选择费用性质；租赁类费用不在本表按面积公摊——外部职场租赁租金/物业由 BB.4.2.a/BB.4.2.a.1 带出、内部场地租赁由 BB.4.2.b 带出（若包含房租付现且符合新租赁准则，路由至 BB.4.2.a.1 外部职场租赁·财务视角或 BB.4.2.b.1 内部职场租赁·财务视角做使用权资产与租赁负债折算）；若 BB.1.4 与 BB.5.2 同时存在，必须配置逻辑开关防止销售费用双重归集。

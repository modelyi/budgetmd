## 表概述

【会计处理】本表不涉及会计处理（仅参数：BAA.9.a 资产转换比例与 BAA.9.b 折旧费用拆分比例，为无PO 资本性支出拆分到法人（BB.3.1.C）与折旧按四大费用拆分（BB.4.5）提供比例，不生成分录）。【法人口径】④不区分法人：比例参数表本身，供 BB.3.1.C 无PO 拆分与 BB.4.5 折旧费用拆分取值，不按法人编制。

## ② 字段与值说明

**BAA.9.a 资产转换比例**

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 预算项目 | AA.6 预算项目主数据字典 | 资本性支出对应的预算项目 |
| 预算部门 | AA.5 行政部门主数据字典（一级部门-二级部门） | 默认二级部门；资本性支出预算编制到二级部门，不归属具体部门的项目可为空 |
| 法人公司占比 | 本表录入 | 按预算项目×预算部门逐行维护各法人公司占比，每行加和必须等于100%（仅文字说明提示，不强制校验/高亮）；为资本性支出法人拆分提供比例 |

**BAA.9.b 折旧费用拆分比例**

| 字段 | 来源 | 说明 |
| :--- | :--- | :--- |
| 资产类别 | AA.9 资产类别与折旧 | 资产类别（代表大类-小类层级，值取 AA.9，如「固定资产-生产机器设备」）；原法人字段已删除，与表样维度列一致 |
| 销售费用比例 | 本表录入 | 百分比 |
| 管理费用比例 | 本表录入 | 百分比 |
| 研发费用比例 | 本表录入 | 百分比 |
| 制造费用比例 | 本表录入 | 百分比 |
| 合计 | 本表公式 | 销售+管理+研发+制造费用比例加和，须=100% |

## ③ 关键规则要点

**BAA.9 资本性支出拆分比例表**

- 本表含两个Tab（同页切换）：资产转换比例（法人拆分）+ 折旧费用拆分比例（费用属性拆分）。
- Tab1 资产转换比例：维度=预算项目+预算部门（预算部门默认二级部门），度量=各法人公司占比+合计列，比例按「预算项目×预算部门」维度逐行维护法人拆分，每行加和须=100%（仅文字说明提示，不强制校验/高亮）；为资本性支出法人拆分提供比例，仅由 BB.3.1.C 财务视角对 BB.3.1.B 无PO表样的采购按 BAA.9.a 拆分到法人（资本性支出法人拆分的唯一入口）。
- Tab2 折旧费用拆分比例：维度=资产类别（层级=大类-小类，与AA.9对齐，已删除法人字段），度量=销售/管理/研发/制造费用比例+合计列；强校验规则：每行四大费用属性比例加和必须强等于100%（Sum=100%）。核心逻辑：专为本年增量资产折旧(BB.4.X)按资产类别拆分到四大费用科目提供比例（增量折旧=各类别新增折旧×对应费用比例）；而存量资产折旧(BB.4.4)依据资产领用部门属性映射(参考AM.2)直接归入对应费用科目，不经过本表拆分。

## ④ 适用业务情形

**适用于**

- Tab1 资本性支出法人拆分比例（按预算项目×预算部门逐行维护各法人占比）：仅由 BB.3.1.C 在无PO采购时按 BAA.9.a 拆分到法人（设备无PO法人拆分的唯一入口，本年度只做一次）；Tab2 折旧费用拆分比例：供 BB.4.5 按 BAA.9.b 将全年及各月折旧拆入四大费用

**不适用于**

- 资本性支出金额填报（属 BB.3.1/BB.3.2/BB.4.1/BB.4.3）
- BB.4.5 的法人拆分（法人直接取 BB.3.1.C 拆分后结果，不重复拆分）

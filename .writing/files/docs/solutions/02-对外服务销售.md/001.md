# 对外服务销售（实施培训手册）

> 一句话讲透本质：**先分清「要不要到现场」——只有现场交付的服务才拆「人工 + 物料」两条明细，其余服务只记一笔收入。**

对外提供技术服务（现场安装、调试、维修、巡检等）。现场交付的服务，成本按「人工 + 物料」两条明细算；其余服务按服务项确认收入，不拆明细。

## ① 在做什么（业务通俗说）

客户买了设备，还要人管装、管调、管修、管巡——这就是对客服务。业务模式：

- 服务合同先签，收入按服务项确认（销量 × 单价，不含税），按月维护；
- **要到现场的**：有人出工、有件换料——成本拆两条：人工（工时 × 费率）和物料（换上去的好件 − 拆回来的坏件）；
- **不到现场的**（咨询、远程支持等）：只记服务收入，不拆明细——没有现场消耗，硬拆料工就是凑数。

物料明细与人工明细两块业务各是一张填报表：存量订单与本年新增都登记在同一张表里，用「订单编号」区分。

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 业务岗（服务/项目） | BB.1.3.a 服务销售 | 填服务项、销量、单价（不含税）、预收与回款 |
| 业务岗（服务/项目） | BB.1.3.d 物料明细 | 填好件、坏件数量——标准成本自动带出 |
| 业务岗（服务/项目） | BB.1.3.g 人工明细 | 填工时——岗位工时费率自动带出 |
| 财务岗 | BB.1.3.c 财务视角；.f / .i 财务查询 | 复核收入成本口径，查看重分类后的账面数 |

## ③ 怎么算账（核心公式与极简算例）

**核心公式：**

- 服务收入 = 销量 × 单价（不含税）
- 人工成本 = 工时 × 岗位工时费率（BAA.3）
- 物料成本 = Σ（好件数量 × 好件标准成本）− Σ（坏件数量 × 坏件标准成本）（BAA.4）——坏件按**坏件**成本冲回，不能取好件成本
- 现金流 = 服务预收 + 回款

**极简算例**（一单现场服务合同）：

| 项目 | 金额 | 怎么来的 |
| :--- | :--- | :--- |
| 收入 | 50 万元 | 一单服务合同，不含税 |
| 人工成本 | 10 万元 | 100 工时 × 0.1 万元/工时 |
| 物料成本 | 7 万元 | 好件 8 万元 − 坏件退库冲回 1 万元 |
| 毛利 | 33 万元 | 收入 50 − 成本 17 |

税率各归各：物料 13%、服务 6%；本表一律不含税，增值税在 BF.4 集中测算。

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 营业收入 | 服务收入按月汇总 |
| 利润表 | 营业成本 | 物料成本 + 人工成本 |
| 资产负债表 | 应收账款 | 收入 − 回款 |
| 资产负债表 | 存货 | 服务领用物料出库减少 |
| 现金流量表 | 提供劳务收到的现金 | 服务预收 + 回款（CF-01） |

人工成本还有个特殊身世：从雇员费用里「重分类」过来——冲减原费用、单列进服务成本；同一批人工只在 BB.5.1 计提一次，不重复计提（详见 04 篇）。

## ⑤ 实施避坑指南

**只有现场服务才拆料工**——不要把不到现场的服务也硬拆人工、物料明细：拆出来的数字没有业务来源，成本配比全乱。

**坏件一定要按坏件成本冲回**——客户现场拆回来的坏件，按坏件标准成本冲减物料成本；图省事拿好件成本冲，物料成本会虚高、毛利失真。

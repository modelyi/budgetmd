# 增值税集中测算（实施培训手册）

> 一句话讲透本质：**业务表只管不含税填报，增值税全部集中算——价外税不进利润，附加税费才进利润表。**

集团各法人均为独立纳税人，增值税按法人分别申报缴纳。各业务编制表一律按不含税口径填报，不在业务表中推导增值税；全部增值税集中在税金及附加预算表中统一测算。

## ① 在做什么（业务通俗说）

增值税这套账只有一个总原则：**业务表不管税，税表管全部。**

- 销售、采购、服务、费用……所有业务表只填不含税金额——单价不含税、金额不含税，谁也不用在业务表里算税；
- 到了 BF.4 税金表，系统把全集团该交的税一次算清：销项（卖东西该收的税）− 进项（买东西已付的税）± 留抵（上期没抵完的）＝ 本期应纳；
- 附加税费（城建税、教育费附加、地方教育附加）以实缴增值税为基数一起算出来；
- 增值税是**价外税**：不影响利润，也不影响存货与资产成本；真正进利润表的是附加税费那部分「税金及附加」。

## ② 谁来填、用什么表（业务与财务分工）

| 谁 | 在哪张表 | 负责什么 |
| :--- | :--- | :--- |
| 各业务岗 | 所有 BB 业务表 | 只填不含税金额，不推税、不算税 |
| 财务/税务岗 | BF.4.b 增值税计提预算表（附表） | 销项、进项按类别自动取数；留抵结转、费用类进项转出、即征即退等特殊事项手工补 |
| 财务/税务岗 | BF.4.a 税金及附加预算表（主表） | 按税种逐月维护计提与缴纳；增值税行默认取附表结果，可结合纳税筹划手工调整 |
| 假设参数层 | AB.15 税率与附加比率 | 税率、附加比率由税务口拍板维护，各表自动带出 |

## ③ 怎么算账（核心公式与极简算例）

**核心公式：**

- 销项税额按收入类别自动取：产品与整机装备销售 13%、技术服务 6%、不动产租赁 9%
- 进项税额按采购类别自动取：物料 13%、设备 13%、基建 9%
- 本期应纳 = 销项税额 − 进项税额 ± 留抵结转
- 附加税费 = 实缴增值税 ×（城建 7% + 教育附加 3% + 地方教育附加 2%）

**极简算例**（某法人某月）：

| 项目 | 金额 | 怎么来的 |
| :--- | :--- | :--- |
| 销项税额 | 130 万元 | 产品销售收入 1,000 万元 × 13% |
| 进项税额 | 104 万元 | 物料采购 800 万元 × 13% |
| 本期应纳 | 26 万元 | 130 − 104（假设无留抵） |
| 附加税费 | 3.12 万元 | 26 × 12%（7 + 3 + 2），进利润表 |

增值税 26 万元不进利润（价外税）：它只影响「应交税费」和缴税现金；附加税费 3.12 万元才是利润表里的「税金及附加」。

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 税金及附加 | 城建税、教育费附加、地方教育附加等附加税费（增值税本身不进） |
| 资产负债表 | 应交税费 | 计提增加、缴纳减少（增值税与附加统一走这一行） |
| 现金流量表 | 支付的各项税费（CF-07） | 按实缴口径 |

三个特殊口径别忘：内部交易卖方计销项、买方计进项（附表单列销项、进项两行，同额同率）；内部借款利息属贷款服务，借入方进项税不得抵扣；软件产品即征即退在附表测算、主表「其中：增值税退税」行列示。增值税按法人分别申报，集团合并时各法人之间不互抵。

## ⑤ 实施避坑指南

**业务表永远填不含税数**——含税金额或税额绝不能进业务表：收入、成本立刻全错，而且到 BF.4 还会再叠一次税。填数之前先问自己一句：这个数是税前的吗？

**增值税 ≠ 税金及附加**——增值税是价外税、不进利润表；进利润表的是以增值税为基数算出来的附加税费。把应纳增值税填进「税金及附加」，利润表直接失真。

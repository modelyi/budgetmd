# 存货流转与成本结转（实施培训手册）

> 一句话讲透本质：**存货是一条流水线——进得来、转得动、出得去；期初 + 转入 − 转出 = 期末，月月轧平。**

全集团存货一条链：采购到货入库 → 生产领用 → 完工入库产成品 → 对外销售或服务领用出库。存货按「法人公司 × 存货类别」逐行、逐月展开。

## ① 在做什么（业务通俗说）

货在集团里「变身」三次，每次变身都是一次转入、一次转出：

1. **原材料**：采购到货 → 转入入库；生产领用 → 转出（变成在制品的「料」）；
2. **在制品**：料（领料）+ 工（制造人工）+ 费（制造费用，含折旧）一起转入；完工 → 按「产量 × 标准成本」转出，变成产成品；
3. **产成品**：完工入库；销售出库 → 结转营业成本（卖出去了，成本跟着收入走）；服务领用 → 出库进服务成本。

所有出入库按法人逐来源取数、不按比例拆分；内部购销（代采、内部物料/产品销售）同样走这条链，加成在合并层处理（详见 AA 方案）。

## ③ 怎么算账（核心公式与极简算例）

**核心公式：**

- 进销存恒等式：期初 + 转入 − 转出 = 期末（按月滚动）
- 完工转出 = 产量 × BAA.2 标准成本
- 销售出库成本 → 营业成本（与销售表的销售成本对上）

**极简算例**（某法人某月，单位：万元）：

| 环节 | 期初 | 转入 | 转出 | 期末 |
| :--- | :--- | :--- | :--- | :--- |
| 原材料 | 100 | 300（采购到货） | 250（生产领料） | 150 |
| 在制品 | 0 | 350（料 250 + 工 60 + 费 40） | 320（完工 = 产量 × 标准成本） | 30 |
| 产成品 | 20 | 320（完工入库） | 300（销售出库） | 40 |

每一格都能对上：行内「期初 + 转入 − 转出 = 期末」，行间「上一环的转出 = 下一环的转入」。

## ④ 三表怎么出（报表落点）

| 报表 | 落在哪一行 | 这一行怎么来 |
| :--- | :--- | :--- |
| 利润表 | 营业成本 | 随销售出库结转 |
| 资产负债表 | 存货 | 期末余额（原材料 + 在制品 + 产成品，按法人逐行汇总） |
| 现金流量表 | （不直接落行） | 存货结转本身不涉及现金；采购付现、销售回款各自在对应业务表口径形成 |

各法人期末余额加总 = 集团存货；期末还没实现的那部分内部加成，由合并层冲减。

## ⑤ 实施避坑指南

**恒等式必须月月轧平**——「期初 + 转入 − 转出 = 期末」是铁律；转出必须和上游表对应（领料对采购、完工对生产、出库对销售），不能手工拍一个数把表填平。轧不平就停下找来源，别硬填。

**完工转出按标准成本、别按实际投入**——在制品完工转出 = 产量 × 标准成本；投入减去转出的差额留在在制品里。拿投入数直接往外转，在制品永远轧不平、产成品成本也没了标准。
